## 1. 层级关系 <a id="layers"></a>

| 层级 | 回答什么 | 目录 |
| --- | --- | --- |
| **架构设计** | 平台由哪几面构成、关键决策是什么（跨阶段稳定） | `架构设计/` |
| **概要设计** | 拆成哪些模块、接口有哪些、数据怎么流 | `概要设计/` |
| **数据库设计** | 哪些数据入库、表集规划、与文件日志的分界 | `数据库设计/` |
| **原型设计** | 管理模块的页面结构、交互与验收基准 | `原型设计/` |
| **项目详细设计** | 每个阶段怎么实现、参数与格式是什么 | `项目/08B_消息平台/设计/` |

**分层纪律**：架构设计管「不随阶段变的决策」，详细设计管「这一阶段怎么做」；两者冲突时以架构设计为准。

## 7. 写文档的口径 <a id="rules"></a>

- **表结构唯一事实源**：数据库设计的数据表文件；总览不复制字段清单。
- **接口唯一事实源**：`deploy/contracts/msg.json` 契约快照；概要设计只列语义。
- **参数不进架构**：默认值、阈值、超时放详细设计与配置说明。
- **设计与实现同步**：实现跑偏先改文档，不让文档追着代码跑。
