## 2. 字段 <a id="fields"></a>

公共字段继承 `BaseModel`；本表为**可重建的观测数据**，不做软删除。

| 字段 | 类型 | 可空 | 约束 / 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | DECIMAL(38,0) | 否 | 主键，雪花 ID | 行主键 |
| `tenant_id` | DECIMAL(38,0) | 否 | 与 `window_start` 复合唯一 | 租户主键 |
| `window_start` | BIGINT | 否 | 与 `tenant_id` 复合唯一 | 窗口起点（epoch 秒，按采样周期取整） |
| `count` | BIGINT | 否 | 默认 0 | 该窗口累计入口条数（多实例增量累加） |
| 审计 / 乐观锁 | — | — | — | `created_at` / `updated_at` / `version`（`BaseModel`） |

**为什么按窗口累加而不是每次发布写库**：发布是热路径；采样器每拍（15s）把本实例增量合并写入，一个窗口内多实例的增量叠加，读侧求和即为集群总量——既避免写放大，也不会重复计数。

## 4. 分片 / 归档 / 建表 <a id="storage"></a>

- **分片**：不分片（平台库常驻）。
- **归档**：不归档；采样器每拍删除早于 1 小时的窗口。
- **建表**：随 **`msg:platform` 清单**表集派生，经幂等建表落地；本阶段无迁移脚本。
