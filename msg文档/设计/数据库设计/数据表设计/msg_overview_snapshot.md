## 2. 字段 <a id="fields"></a>

公共字段继承 `BaseModel`；本表为**可重建的观测数据**，不做软删除。

| 字段 | 类型 | 可空 | 约束 / 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | DECIMAL(38,0) | 否 | 主键，雪花 ID | 行主键 |
| `tenant_id` | DECIMAL(38,0) | 否 | 唯一 | 租户主键（**每租户一行**） |
| `messages_in_per_second` | FLOAT | 否 | 默认 0 | 入口速率（条/秒，最近窗口换算） |
| `consumer_lag` | BIGINT | 否 | 默认 0 | 当前积压（该租户全部主题与组求和） |
| `dlq_total` | BIGINT | 否 | 默认 0 | 死信存量（仅活跃状态） |
| `disk_used_ratio` | FLOAT | 否 | 默认 0 | 磁盘使用率（跨卷取最大） |
| `sampled_at` | DATETIME | 否 | — | 采样时刻（UTC；超过 3 个采样周期视为过期） |
| 审计 / 乐观锁 | — | — | — | `created_at` / `updated_at` / `version`（`BaseModel`） |

**为什么每租户一行而不是每实例一行**：管理台只按当前租户展示四张数字卡；实例级明细由日志与指标出口承担，落库只保留「跨实例统一口径」的一份结果，读侧无需聚合、也不需要清理下线实例的残留行。

**为什么记录 `sampled_at`**：采样器停摆时不能让旧数字永久显示成「当前值」；接口用 45 秒（3 个采样周期）判过期，过期即回退进程内快照。

## 4. 分片 / 归档 / 建表 <a id="storage"></a>

- **分片**：不分片（平台库常驻）。
- **归档**：不归档；采样器覆盖写，行数等于租户数。
- **建表**：随 **`msg:platform` 清单**表集派生，经幂等建表落地；本阶段无迁移脚本（结构以模型为唯一事实源）。
