# msg 前端基类实现契约

> 本仓前端基类的逐类契约与继承链。平台基类语义（体系根、固定三段、组件侧链、形态要求）以 bms《前端基类实现契约》与《前端开发规范》为准，本文件只写 **msg 自己的基类契约与接线**，不复述平台口径。

## 1. 范围 <a id="scope"></a>

- **覆盖**：本仓全部可被继承的类（当前 2 个组件基类产品段：只读视图与写操作，见清单 §2）及其接入平台基类体系的链。
- **不覆盖**：平台基类（权威在 bms）、投影 / 组合式、Vue 页面组件与视图模型、契约生成类型。
- **判定入口**：预检步骤「基座：check_frontend_base」（`[rules.frontend_base]`，`profile = "product"`）。

## 2. 形态契约 <a id="shape"></a>

- `BaseMsgReadOnlyView` 为 TS 类，直接继承平台 `BaseTable`；核心继承链**有且只有一条**，不在投影或页面内并列第二个基类实例形成组合（条文见 bms/bms文档/规范/前端开发规范.md §3.1）。
- 横切行为只经链上基类取得：分页、多列排序、密度、选中集合与列配置来自 `BaseTable` 及其上位能力基类；本类只补产品段语义（只读筛选条件、四态文案键、`msg:query` 权限码判定入口）。
- 公共字段 / 方法只在链上对应基类维护，产品类不重复实现；产品类不声明 dataclass 式的平行状态容器。

## 3. 逐类语义 <a id="each"></a>

### 3.1 `BaseMsgReadOnlyView` <a id="readonly-view"></a>

六类只读页面（平台概览、主题、消费组、分区、消息查询、延迟）与工作台概览卡片的共用横切：

| 能力 | 来源 | 本类补充 |
| --- | --- | --- |
| 分页 / 列配置 / 选中集合 | 平台 `BaseTable` | 不重写，只透传列定义 |
| 加载 / 空 / 错误 / 无权限四态 | 平台上位数据状态基类 | 四态文案键统一走模块 i18n，失败态按错误码映射 |
| 筛选条件 | 产品段 | 主题 / 消费组 / 分区 / offset / key / 时间 / `log_id`，与只读端点查询参数同源；主题授权页的六项筛选经 `replaceFilters()` 一次替换只刷新一次 |
| 权限 | 产品段 | 缺省挂 `msg:query`，无权限不渲染菜单 / 按钮；主题授权页等写管理页可在构造时传 `msg:manage` |
| 取数 | 注入能力 | 一律经宿主 `api.product('msg', 'msg')`，不自建 HTTP、不自拼前缀 |

### 3.2 `BaseMsgWriteAction` <a id="write-action"></a>

六个写操作（新建 / 删主题、扩分区、改保留期、位点重置、配额调整）的共用横切：

| 能力 | 来源 | 本类补充 |
| --- | --- | --- |
| 提交 / 状态机 / 进度 / 取消 / 退避轮询 | 平台 `BaseAsyncTask` | 不重写；`run()` 只做权限前置与清态后交给链上 `submit()` |
| 权限 | 产品段 | 写操作挂 `msg:manage`（页面仍 `msg:query`）；无权限不发请求，直接置 30001 |
| 错误码文案 | 产品段 | 写操作错误码集合（含 `350028`）→ `error.<码>`，未命中回落 `error.fallback` |
| 二次确认 | 产品段 | `requiresConfirm` / `impactRows` / `acknowledge()`：影响范围行由页面按契约字段组装 |
| 结果态 | 产品段 | `errorCode` 在 executor 包装里捕获后再抛，链上 `status` 语义不变；`reset()` 清本轮状态 |

## 4. 投影契约（不入清单） <a id="projection"></a>

- `useMsgReadOnlyView()` 是「核心实例 ↔ Vue 响应式」的**薄适配**，不含判定逻辑；页面只经投影消费，不直接实例化基类。
- 换渲染框架只换投影，链本身不动；投影与平台 `ui_ep` 的 `useBaseTable()` / `useBaseDataState()` 同构。
- 投影不是可继承类，按清单 §3 不登记；但它是「注册必有消费」的接线点，基类落地时须同步提供，否则登记了却无人消费。
- **落地结论（06-1-2，2026-11-09）**：`frontend/modules/msg/src/composables/useMsgReadOnlyView.ts` 已交付，创建基类实例、订阅 `onStateChange`、在作用域卸载时取消订阅；四态 / 错误码 / 竞态 / 筛选判定全在基类与取数层，投影只做加载编排与响应式同步。`useOverviewSnapshot()` 复用同一投影做概览轮询，不另造取数层。
- **落地结论（06-2-2，2026-11-09）**：`frontend/modules/msg/src/composables/useMsgWriteAction.ts` 已交付，订阅链上 `onLifecycle` 同步状态 / 错误码 / 进度 / 结果，`dispose()` 取消在途任务并幂等；权限与错误码判定全在基类。共享件 `MsgConfirmDialog.vue` 只渲染与收集意图（不发请求），06-6-2 / 06-5-2 直接复用。
- **落地结论（06-7，2026-11-09）**：只读投影扩 `permission`（页面权限码，缺省 `msg:query`）、`initialPage` / `initialPageSize`（URL 深链回填）与 `setFilters()`（一次替换全部筛选只刷新一次）；`useAdminRoute()` 增 `path` 与 `replaceQuery()`，主题授权页把过滤与页码写回查询参数且不新增历史。新增 `usePrincipalDirectory()` 只做「标识 → 名称」的分组缓存与失败降级，不实例化基类、不新增可继承层。

## 5. 与平台基类的关系 <a id="platform"></a>

- 平台主干继承链全系统只有 bms/bms文档/前端基类清单.md 一份；本文件只登记产品段，父类经 `[rules.frontend_base].base_source_dirs` 指向 bms 前端 core 源码面解析。
- **不自造根系**：不新增体系根，产品类不直接继承总基类；本仓任何类都必须能追到平台体系根。
- 条文引用：bms/bms文档/规范/前端开发规范.md §3.1、§3.4，bms/bms文档/规范/后端开发规范.md 架构铁律，bms/bms文档/规范/AI开发规范.md 架构铁律「条文引用」，bms/bms文档/设计/基类体系/前端基类实现契约.md。

## 6. 页面消费与验收 <a id="consumption"></a>

- 六类只读页与工作台概览卡片统一经投影消费；后续写操作页面（06-2 / 06-5 / 06-6）与 06-7 / 06-8 追加页面按需复用或新增基类，新增须先登记清单 §2 与本文 §7。
- 契约用例：清单 ↔ 代码 ↔ §7 链三面对账由 `engkit base frontend-base` 承担；变更模块覆盖率口径见 bms/bms文档/规范/AI开发规范.md「覆盖率要求」节。
- 宿主接入：`defineModule` 注册 `routes` / `cards` 属接入机制，不改变本文件的继承链口径。
- **接线结论（06-2-2，2026-11-09）**：四条路由（主题列表 / 详情、消费组详情、配额管理）接入写操作投影；`check_frontend_base` 对账通过（清单 2 个类、§7 两条链）。
- **接线结论（06-7，2026-11-09）**：主题授权页（`views/AclPage.vue`）经只读投影消费并传 `msg:manage`，过滤 / 页码走 `useAdminRoute().replaceQuery()` 深链保持；本轮未新增可继承类，`engkit base frontend-base` 对账保持通过（清单 2 个类、§7 两条链）。
- **接线结论（06-1-2，2026-11-09）**：九个视图（概览、主题列表 / 详情、消费组列表 / 详情、分区、消息查询、延迟、死信与重放）与工作台概览卡片均经投影消费；`engkit base frontend-base` 五项对账全绿（清单 ↔ 源码、§7 链 ↔ 清单、未登记基类、体系根可达、体系根清单小节）；基类与投影的变更模块覆盖率 100% 行 + 分支。
