## 3. 实施过程 <a id="process"></a>

1. 按详细设计先建两份表文件并回写数据库设计总览，再写 ORM 与仓储（幂等建表，无迁移脚本）。
2. 实现 ACL 快照缓存、纯判定、基座 `resource_acl` 端口实现与异步守卫；判定顺序固定 RBAC → ACL → 归属。
3. 接入真实 RBAC：msg 侧远程权限数据源、`prepare_settings` 置 provider、`msg-permissions` 种子写平台权限字典。
4. 接线数据面（publish / consume / ack / nack / join / subscribe）与管理面（topics / groups / delayed / replay / acls）；帧闸门透传 ACL 守卫，补 `BizError` error 帧。
5. 复用 05-4 `emit_acl_change` 写 grant / update / revoke 强审计；ACL 管理路径加入审计中间件排除清单。
6. bms 侧补 `role_ids` 快照字段与 `current_roles()`，`AclContext.roles` 填角色主键；回写 07D `02-5` 文档与记录。
7. 补测试至 53 例（msg 新增）+ bms 3 例；跑选测、静态、类型、契约与覆盖率。

## 4. 关键实现 <a id="impl"></a>

- **表**：`msg_topic_acl` 唯一键 `(tenant_id, namespace, topic, principal_type, principal_key, action)`，不带 `deleted_at`；`msg_topic_acl_scope` 唯一键 `(tenant_id, namespace)` + `scope_version`。
- **判定**：无匹配默认允许；显式 deny 优先；`manage` 不隐含其他动作；user / role 主体；服务身份不匹配 user 规则（本期不受 ACL 限制）。
- **缓存**：每判定读 `scope_version`，变化即重载；两个缓存实例共享版本源；读取异常 `10007 / 503` fail-closed；缓存上限 4096，超限清空。
- **事务**：ACL 守卫读取后释放请求会话事务（`release=uow.rollback`），避免后续 `uow.begin()` 撞「事务已开启」；管理面写前 rollback，版本冲突整批重试一次。
- **管理面**：`GET` 列表（`msg:manage`）、`PUT` 批量授予/更新、`DELETE` 收回；写操作要求目标主题 `manage` ACL；收回软停用。
- **帧路径**：`build_frame_gate` / `_invoke` / `_handle_frame` 透传 ACL 守卫；`_handle_frame` 增 `BizError` 分支，ACL 拒绝返回 error 帧（82013），不落到 JSON 4xx。
- **真实 RBAC**：`prepare_settings` 置 `permission=rbac` / `resource_acl=msg.topic`；数据源不可达 fail-closed；`msg-permissions` 种子 5 个权限码。
- **bms**：`PermissionSnapshot.role_ids` 随缓存载荷往返；`current_roles()` 升序十进制字符串；`AclContext.roles` 由它填充。

## 5. 问题与处置 <a id="issues"></a>

| # | 问题 | 原因 | 处置 |
| --- | --- | --- | --- |
| 1 | ACL 守卫读取后管理面 `uow.begin()` 报「事务已开启」 | 同一请求会话先读后开事务 | 守卫读取后 `release=uow.rollback`；管理面写前显式 rollback |
| 2 | 版本表列名与基类乐观锁 `version` 冲突 | `BaseModel` 已有 `version` | 表列改 `scope_version`，表文件 / 设计同步 |
| 3 | 首次导出契约快照把 10001 写进 `x-error-codes`，清单装载反向校验失败 | 10001 是契约层码，不是产品码 | 从 `_MANAGE_ERRORS` 移除 10001；`git checkout` 旧快照后重新 export |
| 4 | 帧路径 ACL 拒绝可能落 JSON 4xx | 闸门只捕 `MsgError` | `_handle_frame` 增 `BizError` 分支，返回 error 帧 |
| 5 | 测试里 `MsgTopicAcl` 模型与端口同名 | 同名导入覆盖 | 测试端口别名 `MsgTopicAclPort` |
| 6 | 直接 `TopicRepository.create` 后 `uow.begin()` 事务冲突 | 测试 helper 先读 / 写未提交 | helper 建主题后 commit；管理服务写前 rollback |
| 7 | 测试 `filter_allowed` 未命中 deny | 未注入 `user_id_provider`，上下文无 user | 测试显式注入 USER_ID |
| 8 | 覆盖率缺口：缓存溢出 / 端口空缓存 / 校验分支 / 重试分支 | 用例未覆盖 | 补缓存、端口、校验、IntegrityError 重试、帧 ERROR 事件用例 |
