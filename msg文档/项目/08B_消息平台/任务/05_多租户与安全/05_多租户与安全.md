## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：08B 需求域 05 的 7 条扩展项——消息资源作用域、数据面同口径接入、消息维度配额、topic ACL、审计留痕、消息资源生命周期、租户用量板块；继承项见 bms 架构 41 与《[架构设计 · 多租户与安全](../../../../设计/架构设计/07_架构设计_多租户与安全.md)》第 2 节。
- **端范围**：后端（管理面 / 数据面租户链路）+ 前端（msg 管理模块；对 bms 平台的只读暴露经产品声明与契约）。
- **本域性质**：产品侧扩展项——租户解析、状态、认证、RBAC、审计链、通用配额继承基座；msg 只定义消息资源作用域、配额、topic ACL、留痕类别、懒初始化与用量板块，**不写 bms 任何平台表**（隔离纪律）。
- **依据**：bms《[架构设计 · 产品租户与安全接入](../../../../../bms文档/设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》、bms 07D 产品租户与安全接入专项、《[架构设计 · 多租户与安全](../../../../../bms文档/设计/架构设计/41_架构设计_子系统_产品租户与安全接入.md)》、《[架构设计 · 多租户与安全](../../../../设计/架构设计/07_架构设计_多租户与安全.md)》。
- **执行序**：`01_消息模型与投递/01_1_1 租户接入`（已交付，覆盖 `05-1` / `05-2` 的继承接入部分）→ `05-7` 用量板块（本域 01）→ `05-3` 配额（本域 02）→ `05-4` 主题 ACL（本域 03）→ `05-5` 审计留痕（本域 04）→ `05-6` 生命周期（本域 05）。后四条所需基座契约已交付（见下方前置契约注块）：`05-3` ← 07D `02-3`、`05-4` ← 07D `02-5`、`05-5` ← 07D `02-4`、`05-6` ← 07D `01-4`。

> **前置契约（已交付）**：bms 07D 任务 01 通用三级作用域、任务 02 四类标准扩展点（作用域校验 / 错误码映射 / 配额只读回显 / 审计字段扩展）与资源级 ACL 接入约束均已交付；07D 任务 03 已把它们接入 msg（`scope_rule` 命名空间规则、`[[errcodes]].maps_from` 声明、`kind=quota` 数据源声明、`record_ref` 强审计）。扩展项对账表以 bms 任务 03 详细设计为唯一事实源（纯文本路径：`bms/bms文档/项目/07D_产品租户与安全接入/任务/03_产品接入改造/设计/01_详细设计_03_产品接入改造.md`）。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：bms 架构 41（继承 / 扩展边界）；bms 07B `02_03` 种子统一编排、`02_06` 声明注册通道；基座 `form_records()` 表单标识登记；本域 `01_1_1 租户接入`（租户上下文与状态）。
- **风险**：① 继承项被误写成 msg 自建，导致文档与代码事实分叉——以 bms 架构节点为准；② 种子写平台库须与平台编排的 XA 分支一致（不得自行 commit）；③ 表单与字段须与取数端点的列严格同源，否则字段权限与展示会漂移；④ bms 租户管理页内嵌展示需 bms 侧另立任务（本域只保证平台可读的数据与元数据就绪）。
