## 2. 关键实现口径

- **限额与用量分离**：`msg_quota` 只存限额；`usage_snapshot()` 实时汇总主题 / 分区 / 存储 / 今日投递 / 组 / 未确认 / 连接。
- **缺省兜底**：`quota/keys.py` 定义六维缺省值与环境变量覆盖；首次发布懒初始化六条租户级缺省行（`origin=default`）。
- **合并顺序**：命名空间级覆盖 → 租户级 → 内置缺省；`group_count` / `storage_bytes` / `unacked_count` / `connection_count` 仅租户级。
- **软限**：显式软限优先，否则硬限 × 80%；只记状态 / 告警，不改变业务响应。
- **速率**：`RateLimiter.check_quota` 按请求携带的生效速率建桶，配额调整后下一次请求即时生效；静态两级桶行为保留。
- **存储**：目录扫描 `data/{tenant_id}`，TTL 30s；扫描失败返回 `None`（投影 `unavailable`，不拒绝写入）。
- **未确认**：消费入口按租户聚合；达硬限返空批 + `paused=true`，不报错。
- **连接**：仅新连接判定；先租户配额、再副本全局上限，同码 `350020`。
- **投影**：`count` / `bytes` / `qps` 三条声明；`usage=NULL` 不写 0；平台读取器仍按声明单位与周期展示。
- **清理**：租户到期 `purge` 物理删除配额行，并失效配额缓存与存储采样。
- **bms 插槽**：`ModuleAreaOutlet` 新增 `panes` 形态（直接产出宿主 `el-tabs` 子页签）；`DictRecordLayout` 默认区域 `sys.record.detail.tabs`，支持 `moduleArea` / `moduleTabs` / 上下文派生（`formKey` / `recordId`）。
- **页面接入**：租户记录页使用默认区域；用户记录页覆盖为 `sys.user.detail.tabs` 并在新增态关闭模块页签；角色记录页保留 `sys.role.detail.assign` 的页面级挂接位。
- **msg 前端**：模块只注册 `regions` 与 `i18nPacks`；`QuotaPanel` 只读，失败降级、不注册提交器。
