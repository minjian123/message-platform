## 2. 任务内容 <a id="content"></a>

1. **会话隔离**：主题 ACL 守卫的规则 / 版本戳读取改用**独立的平台库会话**，读完由依赖生命周期关闭；守卫不再 `rollback` 请求业务会话。
2. **破面收敛**：判权后读 ORM 行的端点全部恢复可用——主题列表 / 详情 / 删 / 扩、位点重置、死信列表 / 详情 / 重放 / 忽略 / 归档、重放列表 / 详情、ACL 收回。
3. **装配零副作用**：未声明 `resource_acl` 扩展点（最小测试 app / 无 ACL 模型产品）时**不建第二会话**，守卫星照旧短路。
4. **失败语义不变**：ACL 读取失败仍 `10007 / 503` fail-closed；守卫缺仓储属装配缺陷，抛 `ConfigError` 不静默放行。
5. **事务口径**：`TopicAclService.release` 降级为单测直连口（生产装配不再传）；业务侧 `begin()` 前的防御性 `rollback` 保留，不改写语义。
6. **口径保持**：列表 `total` 仍为 ACL 过滤前命中数（与 05-3 实施记录遗留 #7、06-6-1「先分页再按 describe 过滤 items」一致），不借本次改语义。

**边界**：不改 ACL 判定引擎（`decide()`）、缓存与版本戳语义；不新增错误码 / 权限码 / 配置键 / 数据表；不改契约字段；不把演练脚本（`ops/cluster_drill/chain.py`）从直读库改回 API。

## 3. 完成标准 <a id="accept"></a>

- 声明 `resource_acl` 且库里有主题时，`GET /api/v1/msg/admin/topics` 与 `/{id}` 返回 200（修复前 `MissingGreenlet` → 500）；
- 死信列表 / 详情、重放列表 / 详情、位点重置、主题删 / 扩、ACL 收回在同条件下不再 500；
- 无 `msg:query` 仍 30001、`describe` 被拒仍 350027、列表仍按 describe 过滤；
- 未声明扩展点的最小应用行为与既有版本逐项一致（不新建会话、守卫星短路）；
- 变更模块行 + 分支覆盖率达标、静态与文档校验通过；
- 真容器复跑：管理面主题列表 / 详情 200，同源端点 smoke 无 500（除已登记的新建主题挂载竞态）。
