## 2. 任务内容 <a id="content"></a>

> **归属（2026-11-04 拍板）**：本任务**全部在 msg 仓**交付，bms 侧不立项。产品自持链路 = 数据源声明 → 表单/字段种子（写平台库）→ `form_key` 登记 → 取数端点 → 前端页面。

1. **数据源声明**（已有，补齐）：`deploy/registry/msg.toml` 的 `[[data_sources]]`（`msg_tenant_usage`，`origin=product`、`path=/tenant-usage`）补 `allowlist`（`topic_count` / `partition_count` / `storage_bytes` / `delivered_today`），与表单字段同名闭合。
2. **表单与字段种子**：新增 `[[seeds]]` 声明（`service=msg`、`db_key=platform_platform`、`module=msg.seeds.forms`、`entry=seed_usage_forms`、`[seeds.tables]` 声明 `sys_business`=code / `sys_form`=business_id / `sys_field`=form_id,field_key），种子入口在平台编排气泡的 XA 分支内写：
   - `sys_business`：业务码 `msg_usage`（`form_key=msg_usage`，名称「消息平台用量」）；
   - `sys_form`：与业务码 1:1（`component=null`）；
   - `sys_field`：四个字段（主题数 / 分区数 / 消息存储 / 今日投递量，`number` 类型、按 `sort` 排序）；
   - **幂等**：按自然键 upsert，存在且同值跳过、异值报错；不建 `sys_menu_form`、不建按钮。
3. **`form_key` 登记**：新增 `backend/services/form_registry.py`（仿 mdm），`FormRecord(form_key="msg_usage", table="msg_usage", kind=form, data_source_key="msg_tenant_usage")`；`main.py` 覆写 `form_records()` 返回该清单，使 `GET /api/v1/form-keys` 在 msg 进程内可见。
4. **取数端点**：`GET /api/v1/msg/tenant-usage` → `{columns:[{key,label}], items:[], total:0}`（本期固定四列 + 空数据；真实统计随用量表落地）。列与 `sys_field` 同源（同一常量派生）。**限额与预警口径由 msg 给出**（用量 / 限额 / 状态三列，预警与超限阈值按 msg 配额口径判定），平台侧只读展示、不二次计算（原 bms `04_06 产品维度用量汇总` 已并入本任务）。
5. **数据范围过滤（本期后段）**：按平台下推的标准过滤参数解析并作用于查询；未带参数即不过滤。参数名与语法由平台侧定义（bms 侧契约），本任务实现消费。
6. **前端**：msg 管理台「租户用量」页（自有路由，展示同四列）；**bms 租户管理页内嵌板块不在本期**——待 bms 侧立项（槽位/页面声明），本任务只保证平台可读的数据与元数据就绪。
7. **测试**：种子幂等与 XA 语义、`sys_business`/`sys_form`/`sys_field` 落库结果、`form_key` 清单含 `msg_usage`、端点契约与字段一致性、数据范围参数解析；变更模块行 + 分支覆盖率 100%。

## 3. 完成标准 <a id="accept"></a>

- `msg.toml` 声明通过平台装载期校验（种子入口可导入、`[seeds.tables]` 自然键合法）。
- 执行种子后，平台库存在业务码 `msg_usage`、对应表单行与四个字段行；重复执行不产生重复行。
- `GET /api/v1/form-keys` 在 msg 进程内包含 `msg_usage`，`data_source_key` 指向 `msg_tenant_usage`。
- `GET /api/v1/msg/tenant-usage` 返回四列与 `items=[]`、`total=0`；列集合与 `sys_field` 完全一致。
- 角色权限配置在平台侧可选中该表单并为四个字段配置可见性（联合验证，平台侧既有能力）。
- 数据范围参数：带参数时按契约过滤（本期无数据，验证参数解析与透传）；不带参数返回全量。
- 变更模块行 + 分支覆盖率 100%，静态检查全绿。
