## 1. 域说明 <a id="intro"></a>

本域对应需求 [01 消息模型与投递](../../需求/01_需求_消息模型与投递.md)，承载消息平台的语义基础：主题与分区、投递语义、顺序性、消费组、延迟消息、保留与重放、应用固定成本治理、可靠性原语与 outbox 适配。

任务按「一个可独立验收的交付单元」拆分，每条任务对应一条或多条需求，文档格式依 bms《[任务文档规范](../../../../../bms文档/规范/任务文档规范.md)》。

## 3. 依赖与风险 <a id="dep"></a>

| 项 | 说明 |
| --- | --- |
| 上游依赖 | 无（本域是 8B 的首个实现域）；01-8 另依赖 bms `BaseOutboxStore` / relay 现状与 8B_02 存储（已达成） |
| 下游影响 | 存储与复制（域 02）、传输与协议（域 03）、管理与运维（域 06）均依赖本域的分区与 offset 模型；01-8 的 outbox 适配是 8B_04 与 8B_08 迁移的前置 |
| 关键风险 | ① 分区数「只增不减」的约束若在早期未落实，后期扩容会破坏 key → partition 映射；② outbox relay 若长期不换，8B_08 只能迁移 `EventPublisher` 的一半链路，审计事件仍有静默丢失风险 |
