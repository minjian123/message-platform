投递语义用例细目（`broker/test_delivery.py`，22 例）：

| 类别 | 用例 | 断言要点 |
| --- | --- | --- |
| 发布 | 分区与 offset / 空载荷 / 非法 base64 / 命名空间未登记 / 主题不存在 | 同 key 同分区、offset 0→1、`message_id` 不重复且为十进制字符串；空载荷合法；`10001`；`350010`；`350001` |
| 至少一次 | 首次投递 / 空分区 / 超时前不重投 + 超时后重投 | `delivery_count=1`；空批次；1ms 后仍为空 → 过 30s 后同 `message_id` / 同 offset、`delivery_count=2` |
| ack | 顺序推进 / 乱序成段推进 / 成段后保留高位暂存 / 重复 ack 幂等 / 提交失败不前移 / 位点越界 / 未投递 offset | `1`、`0→0→3`、`0→0→2→4`、两次 `1`、`RuntimeError` 后 store 仍为 0 且重试成功、`350002`、`350003` |
| acks=0 | 返回前前移 / 不越过未确认缺口 | 位点直接到 2、再次拉取空；缺口场景只投 offset 1 且位点仍为 0 |
| 毒消息 | 重投 5 次转死信 | `counts=[1..5]`；第 6 次拉取空；死信 `(offset=0, attempts=5)`；位点前移到 1；再 ack → `350007` |
| 其它 | 单次拉取上限 / 投递计数按组隔离 / 位点早于保留起点 | 3 条分两批（`[0,1]` 后 `[2]`）；B 组首投 `delivery_count=1`；`start_offset=5` 的 store 替身 → `350003` |
