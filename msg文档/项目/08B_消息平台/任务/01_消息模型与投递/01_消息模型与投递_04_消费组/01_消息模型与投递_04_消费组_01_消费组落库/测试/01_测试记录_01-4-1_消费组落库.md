## 2. 用例清单 <a id="cases"></a>

| # | 用例 | 关键断言 |
| --- | --- | --- |
| 1 | 组两表往返 | `save` 后重建存储 `load` 快照一致（成员 / 分区 / 世代 / 命名空间），成员行 `instance_id` 落库 |
| 2 | 成员整替 | 再均衡后旧成员行不残留 |
| 3 | 列表 / 删除 | 按租户与主题过滤；删除命中后不可再取，重复删除 False |
| 4 | 空组回收（DB） | `empty` 超期置 `dead`，`stable` 不动，重复执行幂等 |
| 5 | 租户 / 主题清理 | `purge_tenant` / `purge_topic` 物理删除组与成员 |
| 6 | 仓储 / 统计 | `get_by_id` 命中与不存在；`count_for_tenant`；空清理返回 0 |
| 7 | 空组回收（内存） | 只回收空组、幂等启停、默认时钟可用 |
| 8 | 扫描容错 | 单轮异常被吞并下一轮重试；扫描中被停止时取消原样抛出 |
| 9 | 组删除（默认） | 组与成员行消失、位点保留、写 `msg:group.delete` 审计 |
| 10 | 组删除（清位点） | `purge_offsets=true` 时位点被清、响应计数正确 |
| 11 | 组删除错误码 | 缺 `confirm` 10001；组不存在 350013 |
| 12 | 位点清理失败 | 组已删、响应 200、`offsets_purged=0` |
| 13 | B1 新组 | 无提交从 `start_offset` 开始并写实（不再 350003） |
| 14 | B1 已提交被清理 | 有提交且 < start 仍 350003 |
| 15 | `committed` 语义 | 内存 / 文件实现无记录返回 None，提交后返回实际值 |
| 16 | B12 每批判 | ACL 收回后下一批前 `error(350027)` + `close(acl_revoked)` |
| 17 | B12 空闲兜底 | 空闲超阈值同样收尾（用例把阈值调到 1ms） |
| 18 | B19 字节口径 | 同分区跨组同 offset 只算一份；条数仍按组 |
| 19 | 旧记录命名空间补齐 | 缺 `namespace` 的组首次活动时补齐 |
| 20 | 装配 / 钩子 | `DatabaseGroupStore` + `GroupSweeper` 装配；启动钩子拉起、停机停止 |

## 4. 覆盖范围说明 <a id="scope"></a>

- 数据库用例在内存 SQLite 上验证（建表由测试夹具按模型元数据创建），不覆盖真实 MySQL / PostgreSQL / 达梦方言差异。
- 多实例一致性（同一组被两实例同时心跳 / 再均衡）不在本轮，归 02-8-4。
- 长驻流 ACL 复核用替身验证分支；真实 ACL 仓储与缓存由既有权或用例覆盖。
- 前端删除入口为组件级验证（弹窗 teleport 到 body），真机验证随部署窗口。
