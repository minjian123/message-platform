## 2. 任务内容 <a id="content"></a>

1. **后置口径**：明确首期**不实现事务消息**，只保留「半消息 / 回查 / 提交或回滚」的端口位置、事件类型与失败分支，写清触发条件与不做的后果。
2. **CDC 口子**：只保留「outbox connector」形态的口子（消费 outbox 变更并转投）；不做通用 CDC 平台、不接 binlog、不承诺多源同步。
3. **契约占位**：在契约 / 设计文档中给出占位字段与未知字段处理策略，遵循「只增不删、未知忽略、版本可见」；不得让占位字段变成已承诺能力。
4. **边界回写**：把「事务消息 / CDC 后置」写回需求 01-8、架构 09 D17 与规划 §11 的口径，避免迁移期被误读为已支持。
5. **评审**：占位口径须经设计评审；实现事务消息或 CDC 的触发条件与预算在文档中登记，不在本任务内实施。
6. **测试**：占位契约的未知字段 / 版本兼容用例；文档断言「不宣称已支持」；不新增业务能力用例。

## 3. 完成标准 <a id="accept"></a>

- 事务消息与 CDC 的「后置」边界在需求、架构、规划三处口径一致；
- 端口、事件类型与失败分支的占位可被后续任务直接接手，不需要重写契约；
- 不出现「事务消息已支持」「CDC 已接入」等误导性描述；
- 占位契约的兼容用例通过；
- 设计评审记录与回写落点齐全。
