## 2. 任务内容 <a id="content"></a>

1. 产品定位与边界：与 bms 事件总线 / outbox / `HttpServiceClient` / mdm 的关系。
2. 需求：功能与非功能（吞吐、延迟、顺序、可靠、可用、可运维）。
3. 总体架构：传输、协议、消息模型、存储、RPC、HA、多租户、运维。
4. 协议与序列化：HTTP/2 + 二进制（帧、头、负载、错误码、版本）。
5. 存储：追加日志 / WAL / 索引 / 分段 / 保留期 / 崩溃恢复。
6. 消息模型：topic / partition / offset / consumer group / ack / retry / DLQ / replay。
7. RPC：请求/响应、超时、取消、流式。
8. 可靠性与事务：至少一次、幂等、事务消息 / outbox 兼容。
9. 高可用与复制：单机 → 主从 / 分区、故障切换。
10. 多租户、安全与审计。
11. 部署与运维：单服务多域、compose、指标、日志、追踪、管理台。
12. bms 迁移：适配层、切换顺序、回滚开关。
13. PoC 计划：8B_01 的验证项、基准、退出条件。
14. 风险与开放项。
