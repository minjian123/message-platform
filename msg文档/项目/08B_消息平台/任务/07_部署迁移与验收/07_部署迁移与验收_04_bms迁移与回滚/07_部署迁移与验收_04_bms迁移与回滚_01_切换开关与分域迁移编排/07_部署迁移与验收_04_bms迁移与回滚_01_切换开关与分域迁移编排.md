## 2. 任务内容 <a id="content"></a>

1. **迁移前置清单**：逐项核对 8B_05 复制、8B_06 管理、8B_07 隔离与配额、07-1 部署、07-2 凭据、07-3 备份可用；任一项未满足即不进入迁移，清单随任务 `测试/` 留痕。
2. **切换矩阵**：按「事件发布 / 服务调用」两类端口列出可切换域（低风险事件、审计事件、业务事件域、只读远程调用、写远程调用），每个域标注开关键、默认值、观察指标、回滚判据与责任人；缺省值一律为原实现。
3. **配置开关契约**：明确 bms `[event].provider` / `[service_client].provider` 与域级白名单 / 灰度键的语义、合法值、缺省与非法值行为；配置缺失 / 非法时 fail-safe 回原链路；开关变更不要求业务代码发布。
4. **迁移编排**：按「一条低风险事件 + 一个只读远程调用 → 审计事件 → 业务事件逐域」推进；每域切换前备份、切换后观察窗口（错误率、延迟、积压、死信、审计完整性），通过才进入下一域。
5. **在途与双写窗口**：定义切换瞬间的在途请求、未确认事件、outbox 重投、双写窗口处置；优先 drain 后切换，无法 drain 时以幂等键与消费端幂等兜底；禁止在未确认事件未清时切回造成重复或丢失。
6. **fallback 保留**：RocketMQ / outbox / HTTP 原链路在迁移期完整保留；切换与回滚不删除原链路、不改业务端口契约；fallback 可用性纳入观察指标。
7. **仓内交付物**：msg 仓交付迁移矩阵、开关契约说明、跨仓契约用例与演练脚本；bms 真实配置切换、业务域迁移与生产发布由 bms 8B_08 任务承担；两仓独立提交、同步联调。
8. **测试**：开关合法 / 非法 / 缺失三类用例；业务代码零改动断言；一条事件链 + 一个只读远程调用切换成功；fallback 可用性断言；在途 / outbox / 双写窗口用例；两仓契约测试与真实 msg 服务联调。

## 3. 完成标准 <a id="accept"></a>

- 迁移前置清单可核对，8B_05 未满足时明确阻止生产迁移；
- 切换矩阵覆盖事件与服务调用两类端口，每个域有开关键、默认值、观察指标与回滚判据；
- 配置开关语义明确，缺失 / 非法时回原链路，业务代码零改动；
- 至少一条事件链与一个只读远程调用完成切换，观察窗口指标正常；
- 在途 / 未确认事件 / outbox / 双写窗口有明确处置，不产生重复副作用或丢事件；
- fallback 原链路保留且可继续使用；
- 变更模块行 + 分支覆盖率达标，静态与文档校验全绿。
