## 3. 步骤结果 <a id="steps"></a>

| 步 | 结果 | 耗时(ms) | 明细 |
| --- | --- | --- | --- |
| preconditions | ok | 5 | 生产阻断项 2 条（本环境不阻断） |
| matrix | ok | 4 | 5 域 / 3 批次 / 观察窗口 30 分钟 |
| switch_semantics | ok | 5 | event=msg service_client=msg fingerprint=512963d87d6f0325 |
| event_chain | ok | 5 | topic=bms-demo-order payload_digest=d320d879e470af34 |
| readonly_call | ok | 4 | platform.modules.snapshot digest=cd1b3a5c37b278ed count=1 |
| inflight_idempotency | ok | 4 | attempts=2 executions=1 |
| unconfirmed_event | ok | 4 | 不可达抛错；恢复后恰好投递 1 条 |
| dual_write | ok | 5 | 两次调用 = 恰好两条消息（无第二通道） |
| fallback | ok | 5 | http:snapshot digest=cd1b3a5c37b278ed count=1 |
| business_zero_change | ok | 5 | 端口签名不变：3 项 |

- `payload_digest`：`encode_event` 的稳定编码摘要；`readonly_call` 与 `fallback` 摘要相同（两条通道产出同构结果）；
- 在途：首跳注入传输失败、次跳成功，两次帧头 `idempotency_key` 相同，服务端去重后执行 1 次；
- 双写：两次发布 → 恰好两条消息，不存在「两条通道都发」的路径。
