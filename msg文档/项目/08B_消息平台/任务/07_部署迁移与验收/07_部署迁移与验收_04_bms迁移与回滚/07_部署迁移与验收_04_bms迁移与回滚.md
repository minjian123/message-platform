## 3. 任务内容 <a id="content"></a>

1. **适配层复用**：`EventPublisher` / `BaseServiceClient` 的 msg 实现已在 bms `bms_core/msgclient` 落地（04-5 + bms 07B `06_01`），本任务不重复实现协议链，只在 msg 仓交付迁移清单、切换开关契约、回滚开关与演练记录；业务代码不改。
2. **切换层次**：bms 配置层 `[event].provider` / `[service_client].provider` 取 `msg` / 原实现；按事件域与服务域提供白名单 / 灰度开关；缺省为原实现，**未注册实现名或 `msg` 配置不全时装配期拒启**（`PluginError` / `ConfigError`），不静默回落——本条按 [07-4-1 详细设计](07_部署迁移与验收_04_bms迁移与回滚_01_切换开关与分域迁移编排/设计/01_详细设计_07-4-1_切换开关与分域迁移编排.md) §6.2 与 07-4-2 输入基线的定稿口径回写（2026-11-11，原「fail-safe 回原链路」为冲突字面）。
3. **迁移顺序**：一条低风险事件 + 一个只读远程调用 → 审计事件 → 业务事件逐域；每个域切换前确认前置（8B_05 复制、8B_06 管理、8B_07 隔离与配额、备份可用），切换后观察窗口再进入下一域。
4. **回滚开关**：回滚只改配置、不改代码；切回原链路后行为恢复；在途请求、未确认事件、outbox 重投与双写窗口须有明确处置，不得产生重复副作用或丢事件。
5. **fallback 保留**：迁移期保留 RocketMQ / outbox / HTTP 作为 fallback；切换与回滚均不删除原链路、不改业务端口契约。
6. **仓内边界**：msg 仓只做编排与演练；bms 真实配置切换、业务域迁移与生产发布由 bms 仓另立平台级生产部署架构任务承担；两仓独立提交、同步联调，不把 bms 插件代码塞进 msg 仓。
7. **前置硬约束**：8B_05 复制能力未交付前不得进行生产迁移（无复制就迁移等于把单点故障放大到全平台）；本任务在计划中搁置待 8B_05。
8. **测试**：配置开关正反用例；业务代码零改动断言；一条事件链与一个只读远程调用切换成功；切回原链路行为恢复；在途 / outbox / 双写窗口用例；两仓契约测试与真实 msg 服务联调。

## 4. 完成标准 <a id="accept"></a>

- 至少一条事件链与一个只读远程调用切换到 msg，业务代码不改；
- 切回原链路可在配置层完成，不重新发布业务代码，行为恢复；
- 回滚开关已在隔离环境演练过一次，有演练记录；
- 迁移期 RocketMQ / outbox / HTTP fallback 保留，原链路未被删除或改写；
- 8B_05 复制能力作为生产迁移硬前置已确认，未满足不进入生产；
- msg 仓与 bms 仓分工清晰、独立提交，两仓契约测试全绿；
- 变更模块行 + 分支覆盖率达标，静态与文档校验全绿。
