## 1. 域说明 <a id="intro"></a>

- **覆盖范围**：08B 需求域 07 的可执行部分——部署形态与产品声明、配置分层与凭据管理、备份与恢复、bms 迁移与回滚、生产迁移与真实链路联调、压测与容量规划、验收与压测、故障演练、阶段验收；依据《[架构设计 · 部署与运维](../../../../设计/架构设计/08_架构设计_部署与运维.md)》《[架构设计 · 决策与风险](../../../../设计/架构设计/09_架构设计_决策与风险.md)》与《[消息平台规划](../../../../规划/01_规划_消息平台.md)》第 7~9 节。
- **07-5 已在本域建任务**：压测与容量规划归 **8B_12**（独立压测环境、编译型客户端、P50 / P95 / P99 与容量模型定参），任务编号 `07-5`；07-9 只做 8B_09 的验收压测，**不重复取证**，也不以同机基准比值代替容量结论。
- **端范围**：msg 仓部署资产（`deploy/compose/msg.yml`、`deploy/Dockerfile`、`deploy/local_stack.toml`、`.env.example` 与产品声明校验）、备份 / 恢复脚本、迁移编排与回滚演练脚本、生产迁移联调、压测与容量脚本、故障注入脚本、验收压测与阶段验收报告；**不包含** bms 基座网关、认证、Redis、MySQL、可观测后端与业务事件迁移，这些归 bms 仓对应任务。
- **已有基础（复用并补齐，不重做）**：`deploy/registry/msg.toml` 已声明产品档案、服务行、产品路由、数据源、能力、种子、错误码与业务域；`deploy/.env.example` 已列平台接入、数据库、Redis、OTLP 与服务令牌键位；`deploy/compose/` 仅有 README 占位，`msg.yml` 与 `Dockerfile` 尚未落地。02-2 崩溃恢复、02-3 位点文件、02-6 存储水位与 `/readyz` 检查、03-4 连接管理（GOAWAY / drain）、06-3 指标告警、05-3 主题 ACL、05-5 租户生命周期已具备；`EventPublisher` / `BaseServiceClient` 的 msg 适配层由 04-5 与 bms 07B `06_01` 提供，协议链已上移 `bms_core/msgclient`。
- **执行顺序**：`07-1 部署形态与产品声明 → 07-2 配置分层与凭据管理 → 07-3 备份与恢复 → 07-6 故障演练` 已完成；`07-4 bms 迁移与回滚` 已完成（生产迁移仍被 8B_05 闸门阻断）；后续为 `07-8 生产迁移与真实链路联调（待 8B_05）→ 07-9 验收与压测 → 07-5 压测与容量规划 → 07-7 阶段验收`；具体窗口与状态见[阶段计划](../../计划/01_计划_消息平台.md)。
- **执行纪律**：部署与迁移不得修改基座业务代码；凭据只走环境变量、不入库不入镜像；故障演练与恢复演练一律在隔离环境执行并留记录；任务文档不承载进度，进度只在阶段计划回写。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：bms 平台产品装载与服务目录（`deploy/registry/msg.toml` 七段声明）；bms 部署网络与网关（`PLATFORM_NETWORK`、`/api/msg/v1/*`）；02-2 崩溃恢复与 02-3 位点文件（备份 / 恢复与演练）；02-6 存储水位与 `/readyz` 检查；03-4 连接管理（GOAWAY / drain）与 03-5 背压；06-3 指标与告警（演练观测）；05-3 主题 ACL 与 05-5 租户生命周期（迁移期隔离）；bms 07B `06_01` 的适配层与回滚三态；02-8 多实例部署与故障切换验收（07-8 前置）；07-8 生产迁移与 07-9 验收压测（07-7 前置）；07-5 容量实测（8B_12，按可用性引用）。
- **风险**：① 部署资产与基座网络 / 网关 / 产品装载口径不一致，服务起得来但网关不可达；② 凭据落入配置文件或镜像，或公开文档出现服务器 / 内网地址；③ 备份只备元数据、位点与日志不对齐，恢复后位点越尾或丢消息；④ 迁移期双写 / 在途 / 未确认事件处理不当，产生重复副作用或丢事件；⑤ 故障演练在共享环境执行，误伤其他产品；⑥ 阶段验收把「跑过测试」当「有证据」，未通过项默认放行；⑦ 07-5 容量结论若用同机基准比值代替，会与 07-9 的验收压测口径冲突；⑧ 07-8 的真实链路联调若缺 bms 侧协同，生产迁移只能停在编排层。
