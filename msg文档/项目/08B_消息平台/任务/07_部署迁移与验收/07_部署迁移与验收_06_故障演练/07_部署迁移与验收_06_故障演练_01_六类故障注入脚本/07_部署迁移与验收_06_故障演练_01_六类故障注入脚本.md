## 2. 任务内容 <a id="content"></a>

1. **脚本落点**：在 `scripts/drill/`（或 `ops/drill/`）按场景一文件实现注入与清理，统一入口与参数（环境、目标服务、持续时间、是否演练模式）；不把故障脚本混入业务源码。
2. **进程崩溃**：支持 `SIGKILL`（模拟断电 / 崩溃）与 `SIGTERM`（优雅关闭）两档；崩溃后重启，校验已确认消息不丢、未确认可重投、位点不越尾。
3. **磁盘满**：以隔离卷填充 / 容器 quota 模拟；验证发布被拒（`350022` / 507）、`/readyz` 转 503、清理后恢复；不得写满系统盘或共享卷。
4. **慢盘**：以 I/O 延迟或限速模拟（如 `tc` / `fio` / 受控写入），验证不产生假确认、超时可观测、恢复后积压可追平。
5. **网络分区**：以 `iptables` / `tc` 在隔离网络命名空间模拟断连 / 丢包 / 延迟；验证连接断开可重连、无重复消费、退避与重试生效；不涉及多实例选主（归 8B_05）。
6. **消费者卡死**：暂停消费者 / 填满 inflight / 阻塞读，验证积压可见、背压生效、恢复后继续消费；不制造无界内存增长。
7. **毒消息**：注入非法载荷 / 反复失败的消息，验证重试上限、死信落库 / 可查询、不阻塞同分区后续消息。
8. **安全与清理**：所有脚本默认拒绝生产环境，需显式环境开关与二次确认；演练前备份、演练后清理；设置超时与失败兜底，避免环境残留。
9. **测试**：六类脚本 dry-run、参数校验、cleanup 幂等；在隔离环境至少各跑一次；脚本退出码与记录输出可被 07-6-2 消费。

## 3. 完成标准 <a id="accept"></a>

- 六类场景各有独立、可重复执行的注入与清理脚本，参数化且默认拒绝生产；
- 进程崩溃 / 磁盘满 / 慢盘 / 网络分区 / 消费者卡死 / 毒消息均可在隔离环境复现；
- 脚本具备超时、清理与失败兜底，不残留故障状态、不污染共享环境；
- 每类脚本输出可被演练记录消费（注入方式、起止时间、观察指标、结果）；
- 脚本级用例覆盖正常、失败、清理与重复执行；
- 变更模块行 + 分支覆盖率按项目口径达标，静态与文档校验全绿。
