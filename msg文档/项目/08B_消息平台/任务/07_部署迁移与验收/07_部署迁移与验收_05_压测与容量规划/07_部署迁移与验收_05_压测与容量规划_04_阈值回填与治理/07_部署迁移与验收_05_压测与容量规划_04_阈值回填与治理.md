## 2. 任务内容 <a id="content"></a>

1. **清点占位**：汇总各任务遗留的「待 8B_12」阈值与默认值，至少覆盖 07-6 慢盘绝对阈值、06-3 告警阈值、03-5 限速与 `window_stall`、04-4 熔断阈值、02-3 fsync 容量、02-6 容器 quota 读数、06-2 影响预检上限、05-2 配额默认值、03-5 长轮询内存影响、消息检索扫描上限。
2. **逐项定值**：按 07-5-2 / 07-5-3 的实测数据给出推荐值、适用条件与失效条件；无法定值的写明原因、承接方与复核时点，不留「占位」静默交付。
3. **回填落点**：按《AI开发规范》与《数据库开发规范》口径回填到设计文档、规范、配置模板与代码常量；涉及方言 / 实测的标注「实测」或「待验」。
4. **一致性**：同一阈值只维护一处，其他文档引用；计划 §6.1 的遗留台账同步更新状态与归口。
5. **治理**：对已定值但无监控的阈值，补指标 / 告警或说明为何不监控；对已失效的阈值，删除或标注废弃。
6. **边界**：不在本任务内改业务逻辑；阈值变更若影响契约或默认行为，先回写设计与计划再实施。

## 3. 完成标准 <a id="accept"></a>

- 「待 8B_12」的阈值与默认值逐项有结论（定值 / 延期 + 原因 + 承接方 + 复核时点）；
- 已定值项回填到对应设计 / 规范 / 配置 / 常量，引用关系单一；
- 计划 §6.1 台账状态同步，无静默占位；
- 影响契约或默认行为的变更已回写设计与计划；
- 文档三项校验通过。
