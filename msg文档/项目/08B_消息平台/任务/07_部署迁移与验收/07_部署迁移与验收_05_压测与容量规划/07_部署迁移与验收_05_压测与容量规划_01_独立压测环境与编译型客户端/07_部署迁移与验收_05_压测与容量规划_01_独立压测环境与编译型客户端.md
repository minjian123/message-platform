## 2. 任务内容 <a id="content"></a>

1. **分离部署**：压测客户端与 msg 服务分机部署，客户端不与被测服务争抢 CPU / 网络；压测机规格、网络拓扑、目标环境记录在报告里。
2. **编译型客户端**：用 `h2load` 或等价的编译型客户端，替代同机 Python 客户端；支持 h2c / TLS、并发连接数、流数、请求体大小与持续时间参数。
3. **负载档位**：基准、负载、压力三档固定剧本；每档给出并发、消息大小、持续时间、预热与采样窗口，保证不同轮次可比较。
4. **指标口径**：报 **P50 / P95 / P99**、吞吐、错误率、资源（CPU / 内存 / 磁盘 IO / 网络）；不只报平均。
5. **可复现**：脚本、配置、数据生成方式与版本一起入库；同一命令可复跑，报告含版本、配置摘要、环境与原始数据。
6. **边界**：同机 Python 客户端只作诊断记录，不作容量判据；不替代 07-9 的验收压测。

## 3. 完成标准 <a id="accept"></a>

- 独立压测环境可复跑，客户端与服务端分离；
- 编译型客户端覆盖基准 / 负载 / 压力三档，参数可配置；
- 报告含 P50 / P95 / P99、吞吐、错误率与资源数据；
- 脚本与配置入库，同一命令可复现；
- 环境、版本、配置与原始数据记录完整。
