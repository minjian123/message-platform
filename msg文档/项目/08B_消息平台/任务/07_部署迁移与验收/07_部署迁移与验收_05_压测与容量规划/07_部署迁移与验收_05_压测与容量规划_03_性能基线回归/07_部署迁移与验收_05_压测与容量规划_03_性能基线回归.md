## 2. 任务内容 <a id="content"></a>

1. **基线定义**：固定「版本 + 配置 + 环境 + 剧本 + 数据」五要素，形成可比较的性能基线；基线数据与配置一起归档。
2. **回归入口**：提供一条命令 / 一个入口复测基线；03 / 04 / 05 域每次性能敏感变更（传输、序列化、背压、RPC、存储写路径）后按同一入口复测。
3. **对比口径**：与基线对比 P50 / P95 / P99、吞吐、错误率与资源；给出漂移阈值与判定（回归 / 持平 / 改善），不只看单点。
4. **回归报告**：每轮记录变更内容、版本、配置差异、原始数据与结论；异常漂移登记问题或遗留，附定位建议。
5. **与 CI 的分工**：重压测不在提交环 / 推送环跑；CI 只跑轻量门禁，性能回归按需在独立环境执行。
6. **边界**：不替代 07-9 的验收压测；不把同机 Python 客户端数据写入基线。

## 3. 完成标准 <a id="accept"></a>

- 性能基线五要素齐全，可重复复测；
- 回归入口一条命令可用，性能敏感变更后可按同一口径复测；
- 漂移判定有阈值与结论，异常项有记录与归口；
- 回归报告含版本、配置差异与原始数据；
- 重压测不进入提交环 / 推送环。
