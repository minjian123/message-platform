## 2. 任务内容 <a id="content"></a>

1. **真实 RocketMQ 联调**：原链路事件侧真实 broker 可用，验证切回后事件不丢、不重复、位点与审计一致。
2. **生产回滚窗口**：按 07-4 的回滚命令与场景单源，在真实链路执行一次回滚；只改配置、不重新发布业务代码、不删除原链路。
3. **审计对账**：回滚前后审计表行级对账（条数、记录级定位、重复 / 缺失），差异逐条说明。
4. **真实容器演练**：07-6 六类场景在真实容器（`tmpfs` 限额卷）上复跑；容器配额下的水位读数偏差写入偏离项。
5. **真盘演练**：真盘 I/O 延迟 / 满盘注入复跑慢盘与磁盘满场景；绝对阈值引用 07-5-4 的回填值，未定值时记「降级」。
6. **发版流水线**：`release` 接入发版流水线 / 发布检查，发版前自动复跑；失败阻断发布。
7. **记录**：回滚与演练记录含环境、版本、配置、注入、观测、恢复时间、数据完整性、偏离与遗留；失败也落盘。

## 3. 完成标准 <a id="accept"></a>

- 真实 RocketMQ 集群联调通过，切回后行为恢复、无重复、无丢失；
- 至少一次生产回滚窗口演练，审计表行级对账通过；
- 真实容器 / 真盘六类场景可复跑，结论区分通过 / 降级 / 失败；
- `release` 接入发版流水线，失败可阻断；
- 记录完整，未通过项有遗留与归口。
