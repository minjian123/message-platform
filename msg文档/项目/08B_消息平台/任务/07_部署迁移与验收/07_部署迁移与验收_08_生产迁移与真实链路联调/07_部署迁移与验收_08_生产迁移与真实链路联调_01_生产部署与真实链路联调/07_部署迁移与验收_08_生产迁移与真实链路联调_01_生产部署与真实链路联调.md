## 2. 任务内容 <a id="content"></a>

1. **生产部署**：按 07-1 的容器编排与 07-2 的配置分层部署真实 msg 实例；镜像 tag 显式、无 `latest` 兜底；消息日志 / 位点 / 元数据三样持久化。
2. **网关联调**：真实平台网络、产品路由 `/api/msg/v1/msg/...`、h2c / TLS 一跳；`/healthz` / `/readyz` 探针与网关摘流口径一致。
3. **真实服务联调**：真实 platform 服务（认证、租户、审计、服务目录）+ 真实业务服务；跨服务 RPC 的目标方法在 msg 注册表登记；事件发布与消费走真实链路。
4. **审计链**：管理操作、授权变更、访问异常写入 bms 审计链；记录级定位字段可查。
5. **fallback**：真实 RocketMQ / outbox / HTTP 原链路保留且可用；切换前确认 fallback 健康，切换后不删除原链路。
6. **观测**：指标、日志、追踪、探针在真实环境可用；联调期间的异常、延迟、错误码有记录。
7. **记录**：联调方案、命令、配置摘要、结果与问题处置落测试记录；两仓分别提交。

## 3. 完成标准 <a id="accept"></a>

- 真实 msg 实例可部署、可启动，探针与网关路由可用；
- 真实 platform 服务与业务服务联调通过，目标 RPC 方法已登记；
- 审计链端到端可查，记录级定位可用；
- 原链路 fallback 可用，切换前健康检查通过；
- 联调记录完整，问题有处置与归口。
