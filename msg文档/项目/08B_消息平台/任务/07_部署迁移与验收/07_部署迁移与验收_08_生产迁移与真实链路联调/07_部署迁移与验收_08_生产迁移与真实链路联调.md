## 3. 任务内容 <a id="content"></a>

1. **生产前置**：8B_05 复制能力验收通过（02-8），07-1 / 07-2 / 07-3 部署、凭据、备份可用；生产闸门 `check --env prod` 放行，缺一项不迁移。
2. **真实链路联调**：真实 msg 实例（容器 + 平台网络 + 网关 h2c / TLS 一跳）+ 真实 platform 服务 + 真实 RocketMQ / outbox / HTTP fallback；跨服务 RPC 目标方法在 msg 注册表登记；审计链端到端可查。
3. **分域切换**：按 `switch_matrix.toml` 的域级键与白名单 / 灰度，顺序为「一条低风险事件 + 一个只读 RPC → 审计事件 → 业务事件逐域」；每域有观察窗口、回退条件与责任人。
4. **生产回滚**：真实 RocketMQ 集群联调、生产回滚窗口、审计表行级对账；回滚只改配置，原链路保留一个版本，不重新发布业务代码。
5. **真实容器 / 真盘演练**：07-6 六类场景在真实容器（`tmpfs` 限额卷）与真盘 I/O 延迟 / 满盘上复跑；发版流水线接入 `release`，发版前自动复跑。
6. **边界**：不改 bms 端口契约与业务代码；不删除原链路；不替代 07-4 的编排与 07-7 的验收报告；bms 侧配置切换与业务域迁移可跨仓实施。

## 4. 完成标准 <a id="accept"></a>

- 8B_05 复制能力验收通过且生产闸门放行；
- 至少一条事件链 + 一个只读 RPC 在真实链路切换成功，审计事件与业务事件按域推进，业务代码零改动；
- 每域有观察窗口记录与回退判据；至少一次生产回滚窗口演练，审计表行级对账通过；
- 真实容器 / 真盘六类演练可复跑，`release` 接入发版流水线；
- 变更模块行 + 分支覆盖率达标，文档三项校验通过。
