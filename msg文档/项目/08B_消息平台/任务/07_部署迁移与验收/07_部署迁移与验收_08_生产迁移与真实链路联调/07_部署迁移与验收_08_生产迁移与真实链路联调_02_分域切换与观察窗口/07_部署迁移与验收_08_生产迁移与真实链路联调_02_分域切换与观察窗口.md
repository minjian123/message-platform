## 2. 任务内容 <a id="content"></a>

1. **切换矩阵**：按 `switch_matrix.toml` 的域级键与白名单 / 灰度，逐域切换；顺序为「一条低风险事件 + 一个只读 RPC → 审计事件 → 业务事件逐域」。
2. **前置确认**：每域切换前确认复制（02-8）、管理（8B_06）、隔离与配额（8B_07）、备份（07-3）与 fallback 可用；缺一项不切。
3. **在途与未确认**：切换窗口内的在途请求、未确认事件、outbox 重投与双写窗口按 07-4 的处置执行，不产生重复副作用或丢事件。
4. **观察窗口**：每域切换后按固定窗口观察吞吐、延迟、积压、死信、错误率、审计链与告警；记录基线、峰值与异常样本。
5. **回退判据**：每域写明回退触发条件、回退动作与责任人；触发即回退，不「带病观察」。
6. **证据**：切换前后的配置摘要、矩阵勾选、观察数据、问题与处置落记录；与 07-7 的迁移域证据衔接。

## 3. 完成标准 <a id="accept"></a>

- 至少一条事件链 + 一个只读 RPC 在真实链路切换成功，业务代码零改动；
- 审计事件与业务事件按域推进，每域有前置确认与观察窗口记录；
- 在途 / 未确认 / 双写窗口无重复副作用、无丢事件；
- 每域回退判据与责任人明确，触发可回退；
- 证据与 07-7 迁移域证据入口一致。
