## 2. 任务内容 <a id="content"></a>

1. **备份对象与边界**：元数据库随平台库备份，脚本只做「覆盖校验 + 清单登记」，不复制平台库；位点文件按日快照；消息日志不做全量备份，只登记分区段范围与 LEO 摘要。
2. **位点快照**：对 `offsets/{tenant_id}/{group}-{hash8}/` 生成一致性快照（复制时记录文件大小与校验和，避免边写边拷产生半文件）；快照目录与 `data/` 分离，落独立备份卷；保留期可配置，过期快照按策略清理且保留最近一份可用快照。
3. **备份清单**：每次备份生成 manifest（时间戳、服务版本、配置版本、租户列表、表集合摘要、位点文件校验和、分区段范围与 LEO、备份文件清单）；manifest 与备份同目录，供恢复与审计核对。
4. **调度与失败处理**：以平台作业 / cron 定时执行；失败返回非零并输出可定位原因；失败时不得覆盖或删除上一份可用备份；备份目录空间不足时提前失败并告警。
5. **配置口径**：备份根目录、保留天数、平台库连接等全部经配置 / 环境变量读取，不写死路径、服务器地址或凭据；备份脚本不读取 `.env` 明文内容，只消费已注入环境变量。
6. **边界**：不实现消息日志全量归档；不实现跨机房复制；不替代平台数据库备份；不把备份文件提交入库。
7. **测试**：dry-run 不落盘；正常备份生成 manifest 与快照；保留期清理只删过期快照；备份中途失败保留上一份；位点文件写入期间快照校验和稳定；路径与配置项无硬编码断言。

## 3. 完成标准 <a id="accept"></a>

- 元数据库覆盖校验、位点文件日快照、消息日志不备份的口径落地为可执行脚本；
- 每次备份生成可核对 manifest，含版本、配置、租户、位点校验和、分区段范围与 LEO；
- 备份可定时执行，失败非零退出并给出原因，不破坏上一份可用备份；
- 保留期与备份根目录可配置，脚本无硬编码路径、地址或凭据；
- 脚本级用例覆盖正常、失败、清理与并发写入边界；
- 变更模块行 + 分支覆盖率按项目口径达标，静态与文档校验全绿。
