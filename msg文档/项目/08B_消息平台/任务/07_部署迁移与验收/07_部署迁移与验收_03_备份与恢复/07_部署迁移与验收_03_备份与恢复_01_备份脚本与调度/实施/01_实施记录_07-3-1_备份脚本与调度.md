## 3. 实施过程与关键取舍 <a id="process"></a>

```mermaid
flowchart LR
    A["核对输入基线<br/>平台库备份 / 位点目录 / 恢复点"] --> B["逐项拍板 14 项<br/>汇总回显无异议"]
    B --> C["详细设计定稿<br/>链接 / 口径 / 行尾校验"]
    C --> D["落离线命令与常量<br/>纯函数 + 可注入 IO"]
    D --> E["调度模板与键位<br/>宿主侧独立清单"]
    E --> F["Kiwi 2475 先登记<br/>再写 37 例"]
    F --> G["门禁冲突补拍板<br/>C6 宿主例外"]
    G --> H["静态 / 类型 / 覆盖率 / 实证"]
    H --> I["计划 / 架构 / 消费方回写"]
```

1. **宿主离线，不动镜像**：脚本在部署宿主检出仓运行，与平台库备份总控同机同口径；镜像不含 `ops/`，因此不加第三个容器卷、不改 `Dockerfile` 与 `msg.yml`。配置只消费进程环境变量，脚本自身不读 `.env` 明文。
2. **覆盖校验不连库**：从 `MODEL_MODULES` 静态解析期望的 `msg_*` 表集合，与平台 dump（gzip / 纯文本）里的建表语句对账；缺表、无产物、清单解析失败都整份失败，历史多余表只登记。
3. **一致性快照可测**：复制前后双读源文件、副本复算，并与只读取证阶段的 `size` / `sha256` 对账；不一致重试三轮，仍不稳定即整份失败。位点文件本身的「双槽 + 原子替换」是既有事实，重试是并发写入边界的兜底证据，不是正确性前提。
4. **发布原子化**：所有写入先落 `.staging-<标识>/`，校验通过才改名发布并原子写 `current.json`；失败只删临时目录，上一份快照与指针原样不动。清理只删过期且含清单的目录，最新一份与指针所指目录永不删。
5. **单一事实源**：键名与缺省值只在 `core/config.py` 登记，`.env.example` 与调度模板给键位，用例对照三处一致；manifest 字段与恢复侧契约同源，07-3-2 直接按清单复算。
6. **判据函数公开化**：为过 pyright 严格模式的跨模块私有访问检查，脚本里的纯函数与默认 IO 实现统一用公开名，测试替身一律改成带注解的局部函数，不新增任何抑制注释。

## 4. 实施中遇到的问题与处置 <a id="issues"></a>

| # | 现象 | 原因 | 处置 |
| --- | --- | --- | --- |
| 1 | `ops.check_credentials` C6 报 4 项违规 | 07-2 的 C6 把 `.env.example` 全键判为「必须被 `msg.yml` 编排覆盖」，而备份键按拍板不进容器 | 执行中停下逐项补问，拍板「登记宿主例外」：四键加入 `HOST_ONLY_KEYS`，不改注册表、不进编排；T11 补断言。先回写设计对齐记录再继续 |
| 2 | pyright 单文件报 58 项（跨模块私有访问 / lambda 参数未知） | 用例直接测脚本内部函数，且用 lambda 构造 IO 替身 | 脚本判据函数与默认 IO 实现改为公开名；13 处 lambda 改为带注解局部函数；复跑 0 errors，未加任何 `# pyright: ignore` |
| 3 | ruff 要求 3.14 无括号 `except A, B:` 与一处超长行 | 项目 `target-version = py314`，格式化器按 PEP 758 收敛 | 按仓内 `ruff format` 自动格式化，并把 manifest 写入拆成两行；`ruff check` / `format --check` 全绿 |
| 4 | 详细设计与实现的三处口径偏差 | 用例文件由两份合并为一份；一致性判据比设计更严；C6 冲突属原确认范围外 | 按「先回写设计再继续」在 §2 / §9 / §12 补记，未默默绕过 |
| 5 | 本地实证首次 dry-run 与备份都退出 1 | 造数脚本从 `tmp/` 启动找不到 `ops` 包；且命令链中断导致环境变量未导出 | 造数脚本显式把 `backend/` 加入模块搜索路径，环境变量前置导出、各步独立记录退出码；复跑 dry-run 与备份都退出 0 |
| 6 | 计划表新增的实施 / 测试记录链接暂时断链 | 记录文件尚未落盘 | 两份记录落盘后复跑链接校验归零（与 07-2 同一处置） |
| 7 | 部署目录回归日志尾部出现 OTel 导出超时堆栈 | 既有用例退出后后台导出线程写已关闭的流 | 退出码 0、`102 passed`，属既有环境噪音；完整日志落 `.cache/preflight/` 后整体阅读，未据截断输出下结论 |
