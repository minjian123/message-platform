## 4. 覆盖率 <a id="coverage"></a>

按门禁同源插件采集（`MSG_COVERAGE_DATA` / `MSG_COVERAGE_SOURCE`），模块级口径由 `engkit coverage --module ops.backup --fail-under 100` 判定，输出完整落 `.cache/coverage/backup_coverage.log`。

| 模块 | 结果 |
| --- | --- |
| `ops.backup` | `files=1 missing_lines=0 partial_branches=0 percent=100.00` |

覆盖到的分支包括：配置解析的四种非法输入、AST 清单的缺失 / 非元组 / 非字符串元素、dump 的 gzip 与纯文本两种读取、覆盖校验的缺表与多余表、源 / 副本校验和的三条出口、空间判据的通过与失败、原子发布的成功 / 同标识冲突 / 两类 IO 失败、保留期清理的全部保留与删除分支、`main` 的显式参数与默认 `sys.argv` 两条入口。

守门口径：提交环判改动行、推送环与 CI 判模块级；本任务本地跑满变更范围后再交付。
