## 3. 任务内容 <a id="content"></a>

1. **性能验收**：五类压测中的基准 / 负载 / 压力 / 稳定性 / 故障演练；客户端与服务端分离部署；指标报 **P50 / P95 / P99**，不只报平均；记录版本、配置、环境与原始数据。
2. **稳定性**：24 小时 长稳（内存 / 句柄 / 积压 / 延迟 / 错误率），无泄漏、无持续劣化。
3. **故障演练复跑**：07-6 六类场景在验收环境复跑；8B_05 多实例故障切换与网络分区纳入；结论区分通过 / 降级 / 失败，降级项不计通过。
4. **验收证据**：性能报告、稳定性报告、演练矩阵、覆盖率报告、发布记录；证据可复现、链接可达，不复制大段数据。
5. **阶段测试报告**：汇总性能 / 稳定性 / 故障演练结论，给出是否进入 8B_12 与 07-7 的判定；未通过项登记遗留与归口。
6. **边界**：不替代 8B_12 的容量定参与持续回归；不替代 07-7 的九域阶段验收报告；不在本地跑全量测试。

## 4. 完成标准 <a id="accept"></a>

- 五类压测按分离部署执行并产出 P50 / P95 / P99 报告；
- 24 小时 稳定性通过（无内存 / 句柄泄漏、积压可控）；
- 六类故障演练复跑结论明确，多实例故障切换通过；
- 阶段测试报告成文，证据索引完整，未通过项有遗留与归口；
- 覆盖率与文档三项校验通过。
