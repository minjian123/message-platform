## 2. 任务内容 <a id="content"></a>

1. **阶段测试报告**：汇总性能、稳定性、故障演练与迁移结论；每项写判据、证据位置与结论，不用「已测试」代替证据。
2. **证据索引**：测试记录 / 报告 / 演练记录 / 覆盖率报告 / 发布记录逐条链接；证据可复现，不复制大段数据。
3. **判定**：给出「是否进入 8B_12」「是否具备 07-7 阶段验收条件」的明确判定；未通过项登记遗留（现象、根因、影响、承接任务、归口）。
4. **与 07-5 / 07-7 的分工**：07-5 的容量模型与持续回归不在本报告重复；07-7 的九域验收报告由 07-7 汇总，本报告只交阶段测试结论。
5. **一致性**：报告与计划 §5 门禁状态、§6.1 遗留台账一致；数字与证据对得上。
6. **归档**：报告与证据落任务 `测试/`；版本、配置、环境一并记录。

## 3. 完成标准 <a id="accept"></a>

- 阶段测试报告成文，性能 / 稳定性 / 故障 / 迁移四类结论齐全；
- 每项有判据、证据位置与结论，证据链接可达；
- 明确给出进入 8B_12 与 07-7 的判定；
- 未通过项全部登记遗留，含承接任务与归口，无默认通过；
- 报告与计划门禁、遗留台账一致。
