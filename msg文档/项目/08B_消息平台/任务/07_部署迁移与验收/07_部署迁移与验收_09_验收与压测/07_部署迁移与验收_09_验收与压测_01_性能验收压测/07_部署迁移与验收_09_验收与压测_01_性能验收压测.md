## 2. 任务内容 <a id="content"></a>

1. **压测类型**：基准、负载、压力三档为必做；稳定性与故障演练由 07-9-2 承接，本任务不重复。
2. **分离部署**：客户端与服务端分离，使用编译型客户端或等价装置；报 **P50 / P95 / P99**、吞吐、错误率与资源。
3. **场景覆盖**：发布、消费、ack、延迟发布、远程调用一元 / 流式、管理面查询；每类给出请求体大小、并发与持续时间。
4. **环境记录**：版本、镜像 tag、配置摘要、集群规模、网络条件、压测机规格与数据生成方式；保证可复现。
5. **验收判据**：与 07-5 容量模型对照，给出「通过 / 降级 / 不通过」；容量阈值未定值时按 07-5-4 的占位口径记「降级」，不以同机比值代替。
6. **证据**：原始数据、报告与脚本归档；失败与异常样本保留，不只留汇总。

## 3. 完成标准 <a id="accept"></a>

- 基准 / 负载 / 压力三档按分离部署执行，场景覆盖发布、消费、ack、延迟、RPC、管理面；
- 报告含 P50 / P95 / P99、吞吐、错误率与资源；
- 环境、版本、配置与原始数据完整可复现；
- 验收判据与容量模型对照，降级 / 不通过项有遗留与归口。
