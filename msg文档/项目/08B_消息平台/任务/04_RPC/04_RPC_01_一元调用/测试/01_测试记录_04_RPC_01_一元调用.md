## 4. 实测口径 <a id="measure"></a>

```bash

cd backend
MSG_COVERAGE_DATA="<仓根>/backend/.cache/coverage/.coverage" \
  uv run pytest <26 个用例文件> -q

# 判定（14 个模块前缀）
uv run python -m engkit coverage \
  --data-file .cache/coverage/.coverage \
  --out .cache/coverage/report-04-1.json \
  --module bms_msg.rpc --module bms_msg.api.rpc --module bms_msg.client.rpc \

  --module bms_msg.api.router --module bms_msg.main \
  --module bms_msg.api.frame.gate --module bms_msg.api.frame.responses
```

判据来源：`msg.toml` 的 `[coverage]`（`data_env = "MSG_COVERAGE_DATA"`、`fail_under = 100`、`plugin = "engkit.coverage_plugin"`）。
