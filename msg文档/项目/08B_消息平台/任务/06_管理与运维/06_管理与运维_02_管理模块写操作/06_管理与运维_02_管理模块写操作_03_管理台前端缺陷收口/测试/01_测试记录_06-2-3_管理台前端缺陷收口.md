## 2. 用例清单 <a id="cases"></a>

| # | 用例 | 关键断言 |
| --- | --- | --- |
| 1 | 本地 → UTC 带 `Z`，展示转本地 | 往返一致；空 / 非法返回 null 与占位符；空格分隔同样可转 |

| 3 | 语言归一与英文包 | `en-US → en`；宿主 `defaultLocale` / `locale` / `locales()` / `user.locale` 均生效；缺省 `zh-cn` |

| 5 | 连接列表边界 | 未知状态回落原值、空页空态、无权限不取数 |
| 6 | 概览保旧值 | 非首次 loading 仍显示上次数值；失败同时显示错误提示与旧值 |
| 7 | 概览首次加载 | 加载中文案与「上次更新」文案 |
| 8 | 新建主题默认 30 天 | 表单值 30、请求 `retention_ms=2592000000` |
| 9 | 新建主题校验 | 非法名称 / 空命名空间 / 分区越界 / 保留期过短均拦截且不发请求 |
| 10 | 列表状态本地化 | `active → 正常` |
| 11 | 改保留期无变更 | 保存禁用并提示「未做修改」 |
| 12 | 清理进度字段 | 已尝试轮次 / 开始时间 / 最后错误 |
| 13 | 消息深链 | 路径 `logId` + 查询 `namespace/topic` 自动查询一次 |
| 14 | 消息时间非法 | 就地提示且不发请求 |
| 15 | 死信时间非法 | 就地提示 |

| 18 | 配额非法值 | 负数拦截、保存禁用、告警可见 |
| 19 | 配额只读态 | 无 `msg:manage` 时输入禁用、保存入口不渲染 |
| 20 | ACL 复合候选键 | 同名主题跨命名空间产出 `msg/same` 与 `other/same` |

| 23 | 重放表单时间非法 | 返回通用时间错误键 |
| 24 | 确认弹窗错误位 | 错误文案渲染在弹窗内部 |

- 组件级用例在 jsdom 下覆盖交互与状态；浏览器真机（滚动、下拉定位、时区切换）由后续真机验证补充。
