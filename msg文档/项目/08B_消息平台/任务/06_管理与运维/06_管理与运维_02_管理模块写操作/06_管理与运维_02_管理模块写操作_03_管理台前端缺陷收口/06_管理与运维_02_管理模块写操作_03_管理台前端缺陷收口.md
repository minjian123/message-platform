## 2. 任务内容 <a id="content"></a>

1. **数据正确性**：新建主题保留期默认改为 **30 天**（与后端契约一致，原型 04 同步回写）；死信 / 重放 / 消息查询的时间筛选统一「本地时间转 UTC 带 `Z` 上送、展示转本地」；消息查询重置先转「待选条件」再清筛选，避免一次注定 422 的请求。
2. **轮询与请求**：概览轮询不清空已有数值、失败保留上次成功值并提示；筛选改为一次 `setFilters`（不再逐项触发 2~9 次请求）；重放详情抽屉切页签即停轮询并关闭；清理进度轮询改自递归 `setTimeout`，慢响应不堆叠。
3. **写操作**：删主题影响预检失败要在确认弹窗内提示「影响估算不可用」，不得静默吞掉；删除 / 位点重置的失败提示移入弹窗内部；新建主题、配额保存、扩分区、改保留期、死信重放补成功反馈；改保留期两项未变更时禁用保存；配额页补整数 / 非负 / 软限 ≤ 硬限校验与无权限只读态；新建主题补命名空间 / 名称 / 分区 / 保留期校验与命名空间下拉；「下一步」「重新加载」补 loading / disabled。
4. **只读展示**：清理进度补「已尝试轮次 / 最后错误 / 起始时间」；延迟页补主题 / 分区 / 档位筛选；主题详情补容量上限与保留期可读格式；列表时间统一本地化、状态枚举本地化；去掉重复标题；消息查询补 `/msg/messages/:log_id` 深链；延迟页比例与时长统一格式；ACL 主题候选使用命名空间 + 主题名复合键，候选加载失败给出提示。
5. **国际化**：`message()` 按宿主 locale 选择中英文包，英文包真正生效；清理硬编码中文与全角标点。
6. **连接列表页**：新增 `/msg/connections` 路由与页面，调用 06-1-4 的连接列表端点，展示脱敏地址 / 版本 / 开启时间 / 最后心跳 / 长驻流 / 请求数 / 状态；补加载 / 空 / 错误 / 无权限态与分页。
7. **停用 / 启用入口**：依赖 05-4-1 的主题停用 / 启用端点；端点交付前不渲染按钮，交付后由 05-4-1 的前端补充接线，本任务不写死代码。

## 3. 完成标准 <a id="accept"></a>

- 新建主题不动保留期提交，落库为 30 天；原型 04 默认值同步为 30 天。
- 死信 / 重放 / 消息查询的时间窗口与本地选择一致（不再偏 8 小时）。
- 概览 30s 轮询期间数字不闪空；单次失败保留上次成功值并有提示。
- 一次「查询」只发 1 个请求（筛选批量提交）。
- 删主题预检失败时确认弹窗有「影响估算不可用」提示；删除 / 位点重置失败文案在弹窗内可见。
- 写操作成功有明确提示；无变更不提交。
- 连接列表页四态齐全，地址脱敏与分页正确。
- 英文 locale 下管理台文案为英文。
- `msg:lint` / `msg:typecheck` / `msg:test` / `msg:build` / `msg:budget` / `msg:guard` 全绿；变更源文件行 + 分支覆盖率 100%。
