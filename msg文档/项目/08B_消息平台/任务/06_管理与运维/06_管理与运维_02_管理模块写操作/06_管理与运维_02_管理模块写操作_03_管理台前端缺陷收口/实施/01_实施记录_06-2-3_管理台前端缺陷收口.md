## 2. 实施过程 <a id="process"></a>

1. **时间口径**：新增 `services/time-format.ts`（`toUtcParam` / `toLocalText` / `durationText` / `isValidLocal`）；死信、消息查询、重放创建与详情、延迟页全部改「本地时间 → UTC 带 `Z` 上送、展示转本地」，并统一 `time-format` 单一来源。
2. **保留期默认值**：`constants.ts` 新增 `DEFAULT_RETENTION_MS = 2_592_000_000`（30 天）；新建主题表单以「天」为输入单位、提交换算毫秒；原型 04 两处默认值同步 30 天。
3. **国际化**：`runtime.ts` 新增 `normalizeLocale` / `hostLocale` / `readLocaleTag`（宿主 `i18n.defaultLocale` → `i18n.locale` → `i18n.locales()` → `user.locale`，缺省 `zh-cn`）；`message()` 缺省语言改取宿主语言；菜单 / 卡片 / 页签标题与新增文案全部键化。
4. **概览轮询**：`useOverviewSnapshot` 新增 `lastUpdated` 并在成功后记录；`OverviewMetrics` 在「非首次 loading」与「错误但有旧值」时继续渲染上次数值，失败在顶部提示，数值不清空。
5. **批量筛选**：主题 / 分区 / 消息 / 延迟 / 死信 / 消费组与主题详情统一 `setFilters` 一次提交；重置先清表单再一次性提交默认条件；`setActive` 仅在「未激活 → 激活」时取数，消除重复请求。
6. **轮询自递归**：主题清理进度改 `setTimeout` 自递归（慢响应不堆叠、连续失败 3 次暂停并提示）；重放详情抽屉保持自递归，并新增 `active` 联动——切走页签即关闭抽屉停止轮询。
7. **写操作反馈**：新建主题 / 扩分区 / 改保留期 / 配额保存 / 死信处置补成功提示；删除预检失败在弹窗内显示「影响估算不可用」；删除失败文案移入确认弹窗；改保留期两项未变更时禁用保存并提示「未做修改」；配额补整数 / 非负 / 软限 ≤ 硬限校验与无权限只读态；新建主题补命名空间下拉与名称 / 分区 / 保留期校验。
8. **只读展示**：清理进度补「已尝试轮次 / 开始时间 / 最后错误」；延迟页补主题 / 分区 / 档位筛选与档位占比；保留期与时长改为可读格式；列表时间本地化、状态枚举本地化；去掉页面重复标题（统一由 `ReadOnlyList` 头承载）；新增 `/msg/messages/:logId` 深链（`log_id` 来自路径、命名空间 / 主题来自查询参数）；ACL 主题候选改「命名空间/主题名」复合键并补候选加载失败提示。
9. **连接列表页**：新增 `views/ConnectionsPage.vue` 与 `/msg/connections` 路由（order 35），`admin-service.ts` 增 `fetchConnections` / `loadConnections`；页面展示脱敏地址、版本、协议、开启 / 最近请求 / 最近心跳时间、长驻流、请求数与状态，四态齐全并注明「单实例视图」。
10. **构建体积与隔离**：`index.ts` 的文案改为 `setup()` 内动态导入（避免文案包进入容器入口块）；语言解析不读 `document.documentElement`（改用宿主注入 + `user.locale`），产物面隔离护栏恢复零违规。

## 3. 问题与处置 <a id="issues"></a>

| # | 问题 | 处置 |
| --- | --- | --- |
| 1 | 静态导入 `message` 使文案包进容器入口块，体积预算超限（21.3 KB > 19 KB） | 改为 `setup()` 内动态导入，入口回到 10.8 KB |
| 2 | 读 `document.documentElement.lang` 被产物面护栏判「直控根节点」 | 去掉浏览器兜底，语言只认宿主注入（浏览器语言不等于产品语言），护栏零违规 |
| 3 | 既有用例把「读未绑定主题」断言为抛错 | 06-1-4 已改为读返回 0；本任务按新语义维护用例 |
| 4 | 既有用例「改保留期直接提交」在「无变更禁用保存」后不再发请求 | 用例先改值再提交，并补「未变更禁用」断言 |
| 5 | 弹窗内容经 teleport 渲染到 body，`wrapper.find` 取不到 | 用例改用 `document.body.querySelector` + 原生事件 |
| 6 | 删除预检失败原断言「影响表为空」 | 改为断言弹窗内出现「影响估算暂不可用」 |
| 7 | 语言解析曾回落 `navigator.language`，测试环境为 en，导致整套用例变英文 | 去掉浏览器兜底，缺省固定 `zh-cn` |
