## 2. 任务内容 <a id="content"></a>

1. **建主题**：主题列表页“新建”入口，表单含命名空间、主题名、分区数、保留期、容量上限；提交后刷新列表并展示新主题；校验错误按后端错误码定位字段。
2. **删主题**：详情页“删除”入口，二次确认弹窗必须展示影响范围（分区数、消息量、消费组数、延迟待投数、死信数）；确认后提交 `confirm=true`；返回受理结果并展示 `deleting` 状态与清理进度，不假装已立即删除。
3. **扩分区**：详情页“扩分区”入口，输入目标分区数；只允许大于当前值，前端先校验、后端再校验；提交成功后刷新分区列表与缓存相关展示；说明不可减少的原因。
4. **改保留期 / 配额**：详情页与配额页提供调整入口，展示当前值、单位、生效时间；保存后即时刷新；配额调整复用 05-2 页面，不重复建一套表单。
5. **位点重置**：消费组详情页分区行提供“重置位点”入口，输入目标 offset；二次确认弹窗展示组 / 主题 / 分区 / 当前位点 / 目标位点 / 影响（可能重复消费或跳过消息）；提交带 `confirm=true`；结果与错误码可见。
6. **批量重放确认**：重放任务创建页（06-6-2）与死信重放（06-5-2）复用同一二次确认组件，展示范围、条数、速率、目标消费组；确认后才提交。
7. **权限与交互**：写操作按钮挂 `msg:manage`，无权限不渲染；提交中禁用重复点击；失败保留表单并展示错误；成功后跳转或刷新到最新状态；所有影响范围文案入 i18n。
8. **边界**：不在前端伪造成败；不绕过确认参数；不直接调用未登记接口；不做批量脚本入口；不展示消息正文。
9. **测试**：建 / 删 / 扩分区 / 保留期 / 配额 / 位点重置各一条交互用例；确认弹窗影响范围字段；只增校验；无权限不渲染；后端拒绝时的错误展示；原型逐页对照；组件覆盖率 100%。

## 3. 完成标准 <a id="accept"></a>

- 建主题 / 删主题 / 扩分区 / 改保留期 / 配额调整 / 位点重置均有可用页面入口；
- 高危操作二次确认弹窗展示影响范围，提交带 `confirm=true`，缺失时后端拒绝且前端可见；
- 分区数减少在前后端均被拒绝；
- 删除展示 `deleting` 与清理进度，不误导为立即完成；
- 无 `msg:manage` 时写操作入口不渲染；
- 页面逐页对照原型，组件测试与构建体积门禁全绿，变更模块覆盖率 100%。
