## 2. 实施过程 <a id="process"></a>

| 序 | 动作 | 结果 |
| --- | --- | --- |
| 1 | 原型先行（界面先原型） | 04 页补「新建 / 扩分区 / 改保留期 / 删除确认 / 清理中」五个 `?scene=` 场景，05 页补「位点重置」场景，01 页页面规划表同步；两页仍为 Vue 3 + Element Plus 真组件渲染 |
| 2 | 产品段基类 | `BaseMsgWriteAction extends BaseAsyncTask`：`msg:manage` 权限前置（无权限不发请求）、写操作错误码集合（含 `350028`）、确认要求与影响范围、`executor` 包装捕获错误码后重抛 |
| 3 | 投影 | `useMsgWriteAction()`：`onLifecycle` 同步 status / errorCode / progress / result；`dispose()` 取消在途并幂等；权限与映射判定全在基类 |
| 4 | 共享件 | `MsgConfirmDialog.vue`：影响范围表 + 风险提示 + 提交中禁用双按钮 + 默认插槽（位点重置的目标值输入），不发请求 |
| 5 | 页面接线 | 列表页「新建主题」；详情页「扩分区 / 改保留期 / 删除主题」+ `deleting` 告警条、七步进度表与 3s 轮询（主题行消失或状态变化即停）；消费组详情分区行「重置位点」；新增 `/msg/quotas` 配额管理页（作用域切换 + 可编辑硬限 / 软限 + 整批保存） |
| 6 | 取数层 | 五个写函数 + 影响预检；`confirm` 只在高危确认回调里显式传 `true`，不设默认值；必填响应体判定收敛为单一 `required()`（空数据 → 10000） |
| 7 | 文案 | 新增写操作 / 确认 / 清理步骤 / 配额页 / 影响范围行文案与 `error.350028`；顺手补齐 06-1-2 遗漏的 `msg.admin.partitions.lag`（分区页与主题详情此前会显示原始键） |
| 8 | 体积预算 | 构建复测：入口 15.1 KB / 最大块 7.2 KB / 入口外异步块 27 个；阈值维持并更新 `note` 与 `pageChunkHints`（加 `QuotasPage`） |

## 3. 遇到的问题与处置 <a id="issues"></a>

| # | 现象 | 根因 | 处置 |
| --- | --- | --- | --- |
| 1 | 页面用例里「有 msg:manage 但列表无数据」 | 只读投影按 `msg:query` 判定，仅持写权限时页面处于 `denied` | 用例改为同时持 `msg:query` + `msg:manage`（真实管理员视角）；页面权限分层不变 |
| 2 | 弹窗内容在 `wrapper.find` 里找不到 | Element Plus 弹窗内容 teleport 到 body，关闭后保留 DOM（仅遮罩 `display:none`） | 用例统一经 `document.body` 断言，关闭态判 `display === 'none'` |
| 3 | `el-input` 的 `data-test` 落点不稳定 | 属性被组件透传到内部 `input` | 用例选择器兼容「容器 + 内部 input」两种落点 |
| 4 | 覆盖率报两处「不可达兜底」 | `open*` 里对 `detail` 判空、`save()` 里对 `canSave` 再判一次（按钮已禁用，永不可达） | 改为 `watch(detail)` 回填表单、去掉重复守卫，把防御分支变成可构造的正常分支 |
| 5 | 实现快照里告警图标被撑成整屏 | 静态快照页未引组件库 CSS，SVG 无尺寸约束 | 快照页样式补 `.el-alert svg` 尺寸约束与内容区宽度 |
| 6 | 实现快照出现两份相同弹窗 | 弹窗未开 `append-to-body`，本身就在页面根内，又被 body 查询重复收集 | 快照改为只取页面根 `outerHTML` |
