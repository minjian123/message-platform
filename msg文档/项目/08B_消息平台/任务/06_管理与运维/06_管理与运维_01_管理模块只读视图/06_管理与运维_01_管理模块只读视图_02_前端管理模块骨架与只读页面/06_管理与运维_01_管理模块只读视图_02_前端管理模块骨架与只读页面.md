## 2. 任务内容 <a id="content"></a>

1. **原型先行**：补 `msg文档/设计/原型设计/` 下页面 02 平台概览、03 主题管理、04 消费组与积压、05 消息查询、06 死信与重放、08 延迟消息的可交互原型，并更新总览链接与状态；原型定稿后才进入本任务详细设计与实现，验收按原型逐页截图对照。
2. **模块接入**：在 msg 前端模块 `setup()` 中注册 `routes`（管理模块页面）与 1 张 `cards`（消息平台概览卡）；复用宿主布局、动态菜单、权限码、i18n、`api.product('msg','msg')`；不直连宿主 router / store、不自建 HTTP 客户端、不自拼 `/api` 前缀。
3. **页面骨架**：管理模块导航（概览 / 主题 / 消费组 / 分区 / 消息查询 / 延迟 / 死信与重放），列表页统一分页、筛选、空态、错误态与加载态；详情页支持返回与深链；路由 `meta.title` / `meta.icon` / `meta.group` 驱动宿主菜单，详情页 `meta.menu: false`；导航分组为 06-7「主题授权」与 06-8「租户用量」预留位置，两项路由由各自任务在当前模块上追加，不重复搭壳。
4. **只读页面**：概览页四张数字卡 + “查看 Grafana”跳转；主题列表 / 详情（分区 LEO / HW / ISR 占位）；消费组列表 / 详情（成员、分配、分区积压、最后提交时间）；分区详情；消息查询（offset / key / 时间 / `log_id`，只展示头与摘要）；延迟待投与档位分布、堆积提示；死信与重放页的只读入口（写操作与处置交互归 06-2 / 06-5 / 06-6）。
5. **权限与租户**：只读页面与卡片挂 `msg:query`，无权限时菜单 / 按钮不渲染；请求经宿主注入能力携带租户上下文，页面不对租户参数自行拼装。
6. **国际化与文案**：页面标题、字段、错误提示、空态、二次确认文案入模块 i18n 包；错误码文案键按后端错误码映射，不硬编码中文。
7. **工作台卡片**：注册 1 张“消息平台概览”卡片（吞吐 / 积压 / 死信 / 磁盘四值），数据取 06-1-1 概览接口；卡片尺寸、标题、刷新策略按 bms 工作台卡片约定，不另建布局存储。
8. **边界**：不做趋势图自绘（跳 Grafana）；不做写操作；不做消息正文；不改 bms 宿主代码；不引入第二套路由 / 状态 / 请求框架。
9. **测试**：模块契约测试（`routes` / `cards` 注册、命名空间、权限码）；页面组件 vitest（列表 / 详情 / 空态 / 错误态 / 权限）；原型逐页截图对照并登记测试记录；构建体积预算；变更模块覆盖率 100%。

## 3. 完成标准 <a id="accept"></a>

- 原型 02~06、08 已补齐并登记，页面按原型逐页对照通过；
- msg 模块在 bms 宿主注册路由与 1 张概览卡片成功，菜单、权限、i18n、请求能力均走宿主注入；
- 概览、主题、消费组、分区、消息查询、延迟六类只读页面可用，空态 / 错误态 / 权限态完整；06-7 / 06-8 的「主题授权」「租户用量」页面可在此骨架上追加；
- 消息查询只展示头与摘要，不展示正文；
- 模块契约测试、组件测试与构建体积门禁全绿，变更模块覆盖率 100%。
