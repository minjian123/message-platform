## 3. 任务内容 <a id="content"></a>

1. **只读范围**：平台概览、主题、消费组、分区、消息查询、延迟消息六类视图；不提供任何写操作（建删主题、扩分区、位点重置、死信处置、重放归 06-2 / 06-5 / 06-6）。
2. **复用既有端点**：`/admin/topics`、`/admin/groups`、`/admin/delayed` 保持既有契约，按需 additive 扩字段与筛选；不得重命名、不得改响应语义、不得破坏既有调用方。
3. **新增只读接口**：分区详情（leader / LEO / HW / ISR / 已提交位点 / 积压）、消息检索（offset / key / 时间 / `log_id`）、概览聚合（吞吐 / 积压 / 死信 / 磁盘四张数字卡）、延迟档位分布与堆积提示；只返回头信息与载荷摘要，不返回消息正文。
4. **过滤与隔离**：查询按当前租户隔离；支持主题 / 消费组过滤；租户维度过滤受调用方数据范围约束，不得绕过租户上下文直读其他租户数据。
5. **权限**：全部只读端点使用 `msg:query`；无权限不返回数据，前端按钮 / 菜单按权限渲染。
6. **前端接入**：msg 前端模块注册 `routes` 接入 bms 宿主，复用宿主布局、动态菜单、权限码、i18n 与 `api.product('msg','msg')`；管理模块页面按原型总览 02~06、08 逐页实现；另注册 1 张“消息平台概览”工作台卡片。
7. **原型先行**：前端子任务开工前先补对应页面的可交互原型，原型定稿后才进入详细设计与实现；验收按原型逐页截图对照。
8. **边界**：不做趋势图自绘（跳转 Grafana）；不做延迟改期 / 取消；不做消息正文展示；不做跨租户平台级查询（后续按平台运维身份另议）。
9. **测试**：六类视图各有端点级用例；过滤、权限、租户隔离、空数据与非法参数边界；前端模块契约、路由注册、原型对照与构建体积预算；变更模块行 + 分支覆盖率 100%。

## 4. 完成标准 <a id="accept"></a>

- 不登录服务器即可查看主题、消费组、分区 LEO / 积压、延迟待投与档位分布；
- 消息可按 offset / key / 时间 / `log_id` 检索，只展示头信息与载荷摘要；
- 列表支持主题 / 消费组过滤，租户隔离与 `msg:query` 权限可验证；
- HW / ISR 在 02-4 / 02-5 交付前以可空字段返回，不伪造数值；
- 前端页面逐页对照原型，模块路由与工作台卡片在 bms 宿主注册成功；
- 变更模块行 + 分支覆盖率 100%，静态检查全绿。
