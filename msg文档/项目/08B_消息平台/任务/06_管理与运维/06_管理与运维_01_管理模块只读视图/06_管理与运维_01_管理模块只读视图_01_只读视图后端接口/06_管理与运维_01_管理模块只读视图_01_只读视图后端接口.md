## 2. 任务内容 <a id="content"></a>

1. **分区详情**：新增 `GET /api/v1/msg/admin/partitions`，按 `namespace` + `topic` 查询，`group` 可选；返回每分区 `partition` / `leader` / `leo` / `hw` / `isr` / `committed` / `lag`。`hw` / `isr` 在 02-4 / 02-5 交付前返回 `null` / 空集合，不伪造单副本数值；不传 `group` 时 `committed` / `lag` 为空。
2. **消息检索**：新增 `GET /api/v1/msg/admin/messages`，支持 `offset` / `key` / `time_from` / `time_to` / `log_id` 组合过滤（跨类相与），分页 `page` / `size`；返回 `log_id` / `message_id` / `topic` / `partition` / `offset` / `published_at` / `headers` / 载荷长度 / 载荷摘要（哈希或摘要），**不返回消息正文**；`log_id` 精确命中时优先走日志索引，不全量扫描。
3. **概览聚合**：新增 `GET /api/v1/msg/admin/overview`，输出四张数字卡所需值——入口吞吐、当前积压、死信数、磁盘使用率；取自 06-3 的聚合快照与 02-6 / 02-7 的存储 / 延迟指标，不重复采集、不在请求内全量扫描。趋势图不在本接口提供。
4. **延迟汇总**：在既有 `/admin/delayed` 基础上 additive 增加档位分布与堆积提示字段（或新增 `/admin/delayed/summary` 只读端点）；口径与 01-5 待投列表同源，剩余时间按服务端当前时间计算。
5. **筛选与隔离**：所有查询按当前租户隔离；主题 / 消费组过滤复用既有解析与错误码；租户过滤只允许在当前身份数据范围内，不提供跨租户直读入口。命名空间非法 `350010`，主题不存在 / 未启用 `350001`，分区越界 `350009`，分页 / 条件非法 `10001`。
6. **权限**：全部端点挂 `msg:query`，与既有管理面只读端点同码；不新增权限码。
7. **契约**：新增响应 schema 与端点声明 `x-error-codes`；既有端点只做 additive 字段，契约快照随任务重导；不修改 `/admin/groups`、`/admin/delayed` 既有字段语义。
8. **边界**：不做写操作、不做跨租户平台视图、不做正文展示、不做延迟改期 / 取消、不做消息删除；不绕过 `MessageStore` / `OffsetStore` 直接读日志文件。
9. **测试**：分区字段与空值口径；消息检索各条件组合、`log_id` 精确命中、摘要不含正文；概览聚合与采集器一致；延迟档位分布与列表一致；权限 / 租户隔离 / 非法参数；变更模块行 + 分支覆盖率 100%。

## 3. 完成标准 <a id="accept"></a>

- 分区详情可返回 leader、LEO、已提交位点与积压；HW / ISR 字段存在且为可空占位；
- 消息可按 offset / key / 时间 / `log_id` 检索，返回头信息与摘要，不含正文；
- 概览四张数字卡有稳定 JSON 出口，数值与采集器 / 存储快照一致；
- 延迟档位分布与堆积提示可查，与待投列表同源；
- 过滤、权限、租户隔离与错误码符合既有管理面口径；
- 变更模块行 + 分支覆盖率 100%，静态检查全绿。
