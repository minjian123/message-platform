## 1. 概述 <a id="overview"></a>

- **目标**：把管理面「读不到数据目录就 500」、帧错误分类缺口、ACL 码不一致、列表 `total` 口径分叉、分区详情串行等待与连接列表缺失一次收口。
- **口径**：读路径宁可返回 0 / 空页也不报错；错误码只补登记与映射，**不新增产品码**；连接列表只做单实例视图，跨实例归 02-8-4。
- **依据**：任务 [06-1-4](../06_管理与运维_01_管理模块只读视图_04_管理面错误映射与数据口径.md)；05-3-1 已定「列表 `total` 保持 ACL 过滤前命中数」；03-4 连接登记；质量盘点 `tmp/msg-质量盘点-20261113.md` §1~§2。

## 4. 设计 <a id="design"></a>

### 4.1 无数据目录读语义 <a id="unbound"></a>

| 路径 | 未登记目录时的行为 |
| --- | --- |
| `leo` | 返回 0（不创建目录、不抛错） |
| `start_offset` | 返回 0 |
| `fetch` / 消息检索 | 返回空页 |
| `append`（写） | 保持 `PartitionNotBoundError`（fail-closed；正常发布前 `TopicRouter.resolve` 已绑定） |
| 管理面 `PartitionNotBoundError` | 兜底转 `350001`（主题不存在），仅在写路径遗漏时触发 |

实现口径：

- `FileMessageStore` 增加内部 `_locate_or_none()`；读方法先 `_locate_or_none()`，`None` 即按上表返回默认值。
- 管理面 `_inspector()` / `_router()` 统一从 `PartitionDirectoryDep` 取目录（与数据面同源），不再裸构造 `TopicRouter(TopicRepository(session))`。
- 不在读路径调用 `bind()`——避免读请求产生磁盘副作用；绑定仍由 `TopicRouter.resolve`（发布 / 消费）与复制挂载负责。

### 4.2 帧错误分类 <a id="classify"></a>

| 码 | category | layer | retryable | 说明 |
| --- | --- | --- | --- | --- |
| 350025 | `transient` | business | **是** | 主题数配额，等清理 / 调额 |
| 350026 | `transient` | business | **是** | 组数配额，等清理 / 调额 |
| 350027 | `business_reject` | business | 否 | ACL 拒绝 |
| 350028 | `business_reject` | business | 否 | 主题状态非法 |
| 350029 | `business_reject` | business | 否 | 死信不存在 |
| 350030 | `business_reject` | business | 否 | 死信状态不允许 |
| 350031 | `business_reject` | business | 否 | 原记录不可重放 |

改动：`_BUSINESS_CODES` 补 7 个码；`_RETRYABLE_BUSINESS` 补 `350025` / `350026`。`classify()` 函数体不改。

### 4.3 帧 ACL 码映射 <a id="acl-map"></a>

- 帧闸门 `except BizError as exc`：先按 `deploy/registry/msg.toml` 的 `[[errcodes]].maps_from` 反查产品码（82013 → 350027），命中即用产品码构造 error 帧；未命中才用 `exc.code`。
- 反查表在导入期构建一次（`{platform_code: product_code}`），不逐请求读文件。
- 与 JSON 路径的 `maps_from` 单点同源，避免两形态各写一份。

### 4.4 `x-error-codes` 补齐 <a id="declared"></a>

- 所有调用 `acl.authorize` 的端点常量表加 `int(MsgErrorCode.ACL_DENIED)`：`topics` 的 `_QUERY/_CREATE/_WRITE/_DELETE/_IMPACT`，`groups._QUERY`，`dlq` 的查询与四个处置端点，`offsets` 的查询 / 重置，`replay` 的 `_MANAGE`。
- 契约快照重导；`check_modules` 的反向对账随契约通过。

### 4.5 列表 `total` 口径 <a id="total"></a>

- 统一为「ACL 过滤前命中数」（与 05-3-1、重放列表一致）。
- 改 `schemas/delay.py:31/36`、`schemas/group.py:80/83`、`schemas/dead_letter.py:67`、`schemas/admin_view.py:73/77/108` 的描述与字段说明。
- 前端分页按 `total` 渲染；ACL 收回某主题后该页 `items` 可能变少，属预期。

### 4.6 分区详情并发 <a id="gather"></a>

- `PartitionInspector.describe()` 对每个分区构造协程（LEO + 可选组位点 + 复制快照），用 `asyncio.gather` 并发执行，`asyncio.Semaphore(32)` 限流。
- 结果按分区号排序后装配，保持输出稳定。
- 不新增存储端口；单分区调用次数不变。

### 4.7 死信时间区间 <a id="dlq-range"></a>

- `failed_from` / `failed_to` 均给定时，`from > to` 立即返回 `10001`（与消息检索、重放列表一致）。
- 只给一端不校验。

### 4.8 连接列表端点 <a id="connections"></a>

```text
GET /api/v1/msg/admin/connections?page=1&size=20
权限：msg:query
响应：ApiResponse[ConnectionPage]
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `connection_id` | string | `sha1(connection_key)[:12]`，不回传原始键 |
| `tenant_id` | int \| null | 租户内部身份 |
| `remote_prefix` | string | IPv4 `a.b.*.*`；IPv6 前 64 位（前 4 组）；无地址为 `-` |
| `http_version` | string | 协商版本 |
| `scheme` | string | http / https |
| `opened_at` | datetime | 建立时刻（wall clock） |
| `last_seen_at` | datetime | 最近请求时刻 |
| `last_heartbeat_at` | datetime \| null | 最近心跳 |
| `streams` | int | 长驻流数 |
| `requests` | int | 累计请求数 |
| `state` | string | `active` / `idle` / `draining` / `stale` |

- **过滤**：只返回当前租户（`tenant_id == 当前租户`）；匿名连接不展示。
- **排序**：`opened_at` 倒序。
- **分页**：`page` / `size`（`size ≤ MAX_LIST_SIZE`），先过滤排序再切片，`total` 为过滤后总数（此端点无 ACL 行级过滤，与列表口径不冲突）。
- **state 判定**：`stale` > `drain_signaled` > `idle`（最近请求超过空闲阈值）> `active`。
- **多实例**：只反映本进程登记表；文档与响应说明均写明「单实例视图」，跨实例聚合归 02-8-4。

### 4.9 注释与文档对齐 <a id="comments"></a>

- `api/admin/topics.py` 扩分区 docstring：改为「等于现状幂等返回 200；小于现状返回 350009」。
- `api/admin/partitions.py` 文件头：`hw` / `isr` 已接复制协调器真实值（关闭时 `hw=LEO`、`isr=[本节点]`），删除「恒为可空占位」。

## 5. 失败分支 <a id="fail"></a>

| 场景 | 语义 |
| --- | --- |
| 主题存在但本地无目录 | 读返回 0 / 空页；不建目录 |
| 写路径目录未登记 | `PartitionNotBoundError` → 350001 |
| 连接登记表为空 | 返回空页，`total=0` |
| 连接属于其它租户 / 匿名 | 不出现在列表 |
| 帧 ACL 拒绝 | 350027，`business_reject`，不重试 |
| 配额 429 | 350025 / 350026，`transient`，可重试 |
| 死信区间倒置 | 10001 |
