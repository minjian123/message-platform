## 2. 任务内容 <a id="content"></a>

1. **无数据目录读语义**：文件存储在「主题存在但本地尚未登记分区目录」时，读路径（`leo` / `start_offset` / `fetch` / 消息检索）返回 0 / 空页，不创建目录；写路径仍 fail-closed。管理面 `TopicRouter` 按数据面同口径接 `PartitionDirectory`，并以 `PartitionNotBoundError → 350001` 兜底，消除新建主题后查分区详情 / 消息 / 位点直接 500。
2. **帧错误分类补齐**：`api/frame/responses.py` 的 `_BUSINESS_CODES` 补 350025 ~ 350031；`_RETRYABLE_BUSINESS` 补 350025 / 350026（配额超限），350027 ~ 350031 为业务拒绝、不重试。
3. **帧路径 ACL 码对齐**：帧闸门捕获 `BizError` 时按 `errors.py` 的 `maps_from` 映射（82013 → 350027），不再直接透出基座码。
4. **`x-error-codes` 补齐**：所有调用 `acl.authorize` 的管理端点声明 350027（主题 / 组 / 死信 / 位点 / 重放 / 延迟）。
5. **列表 `total` 口径统一**：保持「ACL 过滤前命中数」，把 `delay` / `group` / `dead_letter` / `admin_view` 的 schema 描述改为「过滤前总数」，与 05-3-1 已定口径和重放列表一致。
6. **分区详情性能**：LEO 与复制快照改 `asyncio.gather` 并发取，并发上限 32；调用次数不降、时延下降，不改存储端口。
7. **死信时间区间校验**：`failed_from > failed_to` 返回 10001，与消息 / 重放列表一致。
8. **文档与注释对齐**：扩分区端点的 docstring 改为「等于现状幂等、小于现状 350009」；`api/admin/partitions.py` 文件头的 `hw/isr` 占位表述改为真实值。
9. **连接列表端点**：新增 `GET /api/v1/msg/admin/connections`（`msg:query`、分页、按当前租户过滤），返回脱敏地址（IPv4 只留前两段、IPv6 只留前 64 位）、开启时间、最后心跳、长驻流数、状态；单实例视图，跨实例归 02-8-4。

## 3. 完成标准 <a id="accept"></a>

- 新建主题后立即查分区详情 / 消息 / 位点，均返回 200 与 0 / 空页，不再 500。
- 帧形态遇到 350025 ~ 350031 时，`layer` / `category` / `retryable` 与 JSON 路径一致；ACL 拒绝在两种形态均为 350027。
- 管理端点 `x-error-codes` 均含 350027；契约快照零漂移。
- 列表 `total` 描述统一为「过滤前」，前端按过滤前分页不再出现空页。
- 1024 分区主题的分区详情不再串行等待（并发上限 32）。
- 死信时间区间倒置返回 10001。
- 连接列表端点契约、权限、脱敏与分页齐备；单实例语义在文档写明。
- 变更模块行 + 分支覆盖率 100%，ruff / pyright / 契约 / 文档三项全绿。
