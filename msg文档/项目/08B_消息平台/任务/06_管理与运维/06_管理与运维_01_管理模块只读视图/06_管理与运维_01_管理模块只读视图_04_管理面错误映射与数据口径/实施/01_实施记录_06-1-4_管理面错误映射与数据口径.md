## 2. 实施过程 <a id="process"></a>

1. **无目录读语义**：`FileMessageStore` 新增 `_locate()`；`fetch` / `leo` / `start_offset` / `segments` / `locate` / `read_range` / `read_bytes` / `corrupted_segments` 在未登记目录时返回 0 / 空页 / None；`append` / `truncate_*` / `sync` 仍 fail-closed。
2. **错误映射**：帧闸门 `except BizError` 改用 `bms_core.error_mapper.apply_error_mapper()`，按 `[[errcodes]].maps_from` 把 82013 改写为 350027。
3. **帧错误分类**：`_BUSINESS_CODES` 补 350025 ~ 350031；`_RETRYABLE_BUSINESS` 补 350025 / 350026。
4. **端点声明**：主题（查询 / 创建 / 写 / 删 / 影响预检）、组、死信（查询 / 处置）、位点重置、重放（写 / 进度查询）的 `x-error-codes` 补 350027。
5. **`total` 口径**：`schemas/{delay,group,dead_letter,admin_view}.py` 的「过滤后」统一改为「过滤前」，与 05-3-1 和重放列表一致。
6. **分区详情并发**：`PartitionInspector.describe()` 改为 `asyncio.gather` + `Semaphore(32)`，结果按分区号稳定输出。
7. **死信时间区间**：`failed_from > failed_to` 返回 10001。
8. **连接列表**：新增 `schemas/connection.py` 与 `api/admin/connections.py`（`GET /api/v1/msg/admin/connections`），`msg:query`、租户过滤、`opened_at` 倒序、分页、IPv4 / IPv6 脱敏、连接键短哈希、单实例状态判定；注册到 `api/router.py`。
9. **注释对齐**：扩分区 docstring 改为「等于现状幂等、小于现状 350009」；`api/admin/partitions.py` 文件头的 `hw/isr` 改为真实值。
10. **契约与类型**：`ops.contract_snapshot export` 重导；`api-types` 重新生成。
