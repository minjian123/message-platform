## 1. 任务边界与已确认口径 <a id="scope"></a>

**本任务做什么**

1. 补 `msg文档/设计/原型设计/10_原型设计_租户用量.html`（7 场景），同步总览页面 10 行与 02~09 各页导航入口。
2. msg 后端新增管理面只读端点 `GET /api/v1/msg/admin/tenant-usage`（挂 `msg:query`、套统一响应），内部复用 05-1 的用量快照服务与列清单，**不改** 05-1 端点、表单元数据与表结构。
3. 前端新增独立页 `/msg/usage`（路由名 `msg.usage`，菜单「租户用量」，order 90，`msg:query`，图标 `el:DataAnalysis`）：四张数字卡 + 口径说明区 + 手动刷新。
4. 前端向 bms 租户记录页注册 `regions` 项（`sys.record.detail.tabs`、标题「消息用量」、order 41、`msg:query`、仅 `formKey === 'tenant'` 渲染）：四卡 2×2 + 当前登录租户提示 + 「打开用量页」链接。
5. 抽公共数值格式化（计数千分位、字节 1024 进制），`QuotaPanel` 改为引用，同一单位口径只有一份实现。
6. 测试：后端端点用例、前端组件 / 服务 / 契约用例、原型逐页截图对照、变更模块行 + 分支 100%。

**不做什么**

- 不改 05-1 端点（`/api/v1/msg/tenant-usage` 及其 quota 三条投影）、`deploy/registry/msg.toml` 数据源声明、`sys_form` / `sys_field` 种子；
- 不新建表、不改字段、不做迁移；
- 不做跨租户用量列表、租户切换、数据范围过滤；
- 不自绘趋势图（趋势走 bms Grafana），不提供 Grafana 链接按钮（该常量当前为空，加了也不渲染）；
- 不与配额页签重复展示限额 / 软硬限状态；
- 不改 05-2 已交付的「消息配额」页签（含其提示口径）；
- 不自建 HTTP 客户端、不自拼 `/api` 前缀、不在前端重算用量。

## 4. 后端：管理面租户用量只读端点 <a id="backend"></a>

### 4.1 端点契约

| 项 | 值 |
| --- | --- |
| 方法与路径 | `GET /api/v1/msg/admin/tenant-usage` |
| 权限 | `msg:query`（`dependencies=[Depends(require_permission('msg:query'))]`） |
| 响应 | `ApiResponse[TenantUsageView]`，`data = {columns:[{key,label}], items:[row], total:1}` |
| 错误码声明 | `x-error-codes = [TENANT_SUSPENDED, TENANT_NOT_FOUND]`（经租户中间件入口拒绝） |
| 租户 | 取 `CurrentTenantDep`，不接受 `tenant_id` 入参（无法跨租户） |
| 取数 | `UsageSnapshotDep.snapshot(tenant_id)` + `column_payloads()` + `usage_row()` |

`items` 恒为一行：四列值来自同一次快照。`total` 恒为 `1`（与 05-1 同构，前端不据此分页）。

### 4.2 响应结构

```text
TenantUsageView
├── columns: [{ key, label }] × 4      # 顺序即 USAGE_COLUMNS 顺序
├── items:   [TenantUsageRow] × 1
│            ├── topic_count: int
│            ├── partition_count: int
│            ├── storage_bytes: int | null      # 目录扫描失败即 null
│            └── delivered_today: int
└── total:   1
```

### 4.3 代码落点

```text
msg/backend/services/msg/src/bms_msg/
├── api/admin/usage.py            # 新增：BaseRouter(key=msg_admin_tenant_usage, prefix=/msg/admin/tenant-usage)
├── api/router.py                 # api_router 追加 admin_usage.router（先 quota 后 usage，声明序即对外顺序）
├── schemas/usage.py              # 新增：UsageColumnView / TenantUsageRow / TenantUsageView
└── usage/columns.py              # 新增：usage_row(snapshot) -> ConcurrentStableDict[str, int | None]

msg/backend/services/msg/src/bms_msg/api/admin/quota.py
└── 删 _usage_row()，改 from bms_msg.usage.columns import usage_row
```

- `usage_row()` 是「快照 → 四键行」的**唯一装配**：按 `USAGE_COLUMNS` 遍历取 `getattr(snapshot, key)`，键序与列序一致，未知键得 `None`。
- 新端点不写任何聚合查询、不扫目录、不读缓存，只调服务。
- `schemas/usage.py` 的 `TenantUsageRow` 用固定四个字段（而非动态字典）：契约可生成、前端类型可索引、字段集合可被用例断言；字段值允许 `None` 的只有 `storage_bytes`（与快照语义一致）。
- 集合声明一律用 `ConcurrentStableList` / `ConcurrentStableFrozen*`（裸集合护栏）。

### 4.4 与 05-1 的关系

| 维度 | 05-1 `/api/v1/msg/tenant-usage` | 06-8 `/api/v1/msg/admin/tenant-usage` |

| 权限 | 无（平台内部读取） | `msg:query` |

| 列口径 | `USAGE_COLUMNS` | 同 |

## 5. 前端取数层与数值格式化 <a id="services"></a>

### 5.1 `usage-service.ts`

| 导出 | 语义 |
| --- | --- |
| `TenantUsageView` / `UsageColumn` / `TenantUsageRow` | 取 `@msg/api-types` 的 `msg.components['schemas']` |
| `UsageCardRow` | `{ key: string; label: string; value: number \| null }`（页面渲染单元） |
| `fetchTenantUsage()` | `getData<TenantUsageView>('/admin/tenant-usage')`，空回落 `{columns:[],items:[],total:0}` |
| `loadUsageCards()` | `ReadOnlyLoader<UsageCardRow>`：取数 → 按 `columns` 顺序映射四行 |
| `USAGE_CAPTION_KEYS` | 列键 → 卡片口径短句键（`topic_count` → `msg.usage.caption.topicCount` 等） |

`loadUsageCards()` 的三条硬约束：

1. **不重算**：只做「列键 → 行值」取值，不做加减乘除；字节换算只发生在渲染层。
2. **列元数据缺失即契约违背**：`columns` 为空时抛 `MsgQueryError(10000)`，让页面落 `error`（不产生 `empty` 分支）。
3. **`items` 为空不报错**：所有 `value` 取 `null`，四卡各显示「暂不可用」，页面仍为 `ready`。

### 5.2 `usage-format.ts`

| 导出 | 语义 |
| --- | --- |
| `STORAGE_BYTES_COLUMN` | 需要按字节展示的列键（`storage_bytes`） |
| `UNAVAILABLE_KEY` | 不可用文案键（`msg.quota.state.unavailable`） |
| `splitBytes(value)` | 字节拆成 `{amount, unit}`：1024 进制、封顶 TiB、整数不带小数、非整数保留一位（取整在此完成） |
| `formatBytes(value)` | 整串文本（`3.4 GiB`），供配额页签等需要单串的场景；`null` / 非有限数 → 「暂不可用」 |

- 计数类**不做前端格式化**：把原始数字与 `format='number'` 交给平台指标卡，由其 `Intl` 口径出千分位；否则格式化后的字符串会被指标卡判为空值并渲染 `—`。
- `splitBytes` 承担「非整数保留一位」：指标卡按 `number` 输出数值时自行决定小数位，直接传 `8.7412…` 会显示三位小数。
- `formatBytes` 由 `QuotaPanel` 的私有 `humanBytes` 迁入（换算与精度逐字保留，行为不变）；`QuotaPanel` 改为 `import { formatBytes }`。
- 单位封顶后仍显示 TiB 数（不引入 PiB），与配额页签一致。

## 7. 页面与组件分层 <a id="page"></a>

### 7.1 组件结构

```text
UsagePage.vue                        # 独立页 /msg/usage
├── 头部：标题 + 副标题 + 刷新按钮
├── UsageCards.vue（layout="4"）     # 四张 MetricCard
├── 口径说明区（el-descriptions 或列表）
└── el-alert（error / denied 态，替代四卡）

UsagePanel.vue                       # 租户记录页「消息用量」页签
├── 提示行：当前登录租户 + 记录页租户标识
├── UsageCards.vue（layout="2"）
├── el-link「打开用量页」→ /msg/usage
└── el-alert（error 态降级，不阻塞宿主）
```

### 7.2 `UsageCards.vue`

| Prop | 语义 |
| --- | --- |
| `rows` | `UsageCardRow[]`（四行，来自 loader） |
| `state` | `ReadOnlyViewState`（仅用于「首次加载出骨架」判定，不影响已有值的展示） |
| `layout` | `4`（独立页一行四列）或 `2`（页签 2×2），决定 CSS grid 列数 |

渲染规则：

- **首次加载**（`state === 'loading'` 且 `rows` 为空）→ 四块 `el-skeleton`；**刷新中**（有 `rows`）→ 保留旧值，避免把已看到的数字换成加载文案。
- 每张卡：`MetricCard`，`title=row.label`、`value=数值`（字节列经 `splitBytes` 拆成 `value` + `unit`）、`format='number'`、`caption=message(USAGE_CAPTION_KEYS[row.key])`、`ready=(row.value !== null)`。
- **单列不可用**（`value === null`）：走指标卡的 `#degrade` 插槽自绘「标题 / 暂不可用 / 脚注」，保持与其余三卡同构（默认占位态只渲染一句文案，会丢标题与脚注）。
- 隐藏指标卡自带的卡内「刷新」（整页 / 整页签统一刷新入口，四张卡各带一个既重复又挤占页签宽度）。
- `data-test="usage-card-<key>"`，便于用例逐卡断言；组件不取数、不管权限。

### 7.3 `UsagePanel.vue`（页签）

- `formKey = useModuleSlotField<string>('formKey')`；`visible = computed(() => formKey.value === 'tenant')`，否则渲染空容器。
- `recordId = useModuleSlotField<string>('recordId')`：仅作**对照展示**，不参与取数（后端以租户上下文为准）。
- 提示行：`按当前登录租户统计 · 记录页租户 {recordId}`；`recordId` 为空时只显示前半句。
- `msg:query` 缺失 → `denied`：不渲染四卡与提示行，渲染 `el-alert`（`msg.usage.unavailable`），**不渲染跳转链接**（避免跳到同样无权限的页面）。
- 请求失败 → `el-alert` 降级，不影响宿主页其它页签。
- 跳转：`useAdminRoute().go('/msg/usage')`，不自行操作 `router`。

### 7.4 `UsagePage.vue`（独立页）

- `useMsgReadOnlyView<UsageCardRow>({ loader: loadUsageCards, permission: MSG_QUERY_PERMISSION })`；无分页。
- `state === 'denied'`：`el-alert`（`state.denied`），不渲染四卡。
- `state === 'error'`：`el-alert`（`errorTextKey()`）+ 「重新加载」按钮；不渲染四卡。
- 其它：四卡（`layout=4`）+ 口径说明区（五条：四项口径 + 数据来源 + Grafana）。
- 刷新按钮调 `refresh()`；刷新期间 `state === 'loading'` 时卡片显示骨架，不整页闪烁。
- 页面不自带列表骨架（`ReadOnlyList` 面向分页列表，本页无分页与筛选）。

## 8. 失败分支、权限与降级 <a id="failure"></a>

### 8.1 权限

| 层 | 权限 | 说明 |
| --- | --- | --- |
| 菜单 / 路由 | `msg:query` | `meta.perm`，宿主守卫拦截 |
| 页签 | `msg:query` | region 项 `perm`，无码不渲染 |
| 页面状态 | `msg:query` | 投影 `permission`，缺码显示 denied |
| 端点 | `msg:query` | 后端 `require_permission` |

### 8.2 分支矩阵

| 场景 | 独立页 | 页签 |
| --- | --- | --- |
| 无 `msg:query` | `el-alert`（`state.denied`），无四卡 | `el-alert`（`msg.usage.unavailable`），无四卡、无跳转 |
| 请求失败（任意码） | `el-alert`（`error.<码>` 或兜底）+ 重新加载 | `el-alert` 降级，宿主其它页签不受影响 |
| `columns` 为空（契约违背） | `error` 态（`error.10000`） | 同（落 error 降级） |
| `storage_bytes = null` | 该卡显示「暂不可用」，其余三卡正常 | 同 |
| `items` 为空 | 四卡全「暂不可用」，页面 `ready` | 同 |
| 宿主请求能力缺失 | `error` 态（`MODULE_API_ABSENT` → 兜底文案），不白屏 | 同 |
| 非 `tenant` 表单 | — | 空容器，零请求 |

### 8.3 错误码映射

沿用 `BaseMsgReadOnlyView` 的 `errorKeyOf`：登记码走 `error.<码>`，未登记走 `error.fallback`。本端点只声明 `350001` / `350010` 类租户码与通用码，不新增错误码、不改文案表。
