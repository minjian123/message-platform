## 2. 任务内容 <a id="content"></a>

1. **任务列表**：新增 `GET /api/v1/msg/admin/replay`，按状态 / 主题 / 时间过滤，分页 `page` / `size`；返回任务摘要（`task_id` / 主题 / 状态 / 进度 / 速率 / 创建时间 / 终态时间）；既有 `GET /admin/replay/{task_id}` 契约不变。
2. **影响基线**：创建任务时解析该主题的消费组（按组订阅关系），记录受影响组与创建时积压基线；基线存 `msg_replay_task` 新增 JSON 列（如 `impact_groups`），**先改表文件并追加变更记录**，再改模型与响应 schema。
3. **影响详情**：任务详情 additive 返回 `affected_groups`：`group` / `baseline_lag` / `current_lag` / `delta` / `captured_at`；当前值按组 + 分区 `LEO - committed` 计算，复用 01-4 口径；任务终态后保留最后快照。
4. **终态同步**：死信重放（06-5）创建的任务在进入 `completed` / `failed` / `cancelled` 时，提供可查询的终态与回写入口；由死信状态同步器或查询时惰性回写，不重复实现重放状态机。
5. **权限与租户**：列表 / 详情 `msg:query`，创建 / 暂停 / 恢复 / 取消沿用 01-6 的 `msg:manage`；任务按租户隔离，跨租户不可见；错误码沿用 `350016` / `350017`。
6. **边界**：不改 01-6 限速、暂停 / 恢复 / 取消与 `log_id` 分配语义；不跨租户重放；不重做执行器；影响视图只读。
7. **测试**：列表过滤 / 分页 / 空态；基线采集与当前值计算；无消费组时影响为空；任务终态快照保留；死信任务终态回写；权限 / 租户隔离；既有 01-6 用例回归；变更模块行 + 分支覆盖率 100%。

## 3. 完成标准 <a id="accept"></a>

- 重放任务列表可分页 / 过滤，字段与详情一致；
- 创建任务时记录受影响组与积压基线，详情可见基线 / 当前 / 变化；
- 无订阅组时影响为空且不报错；
- 任务终态后影响快照保留，死信任务终态可回写；
- 既有 01-6 契约与状态机零破坏；
- 变更模块行 + 分支覆盖率 100%，静态检查全绿。
