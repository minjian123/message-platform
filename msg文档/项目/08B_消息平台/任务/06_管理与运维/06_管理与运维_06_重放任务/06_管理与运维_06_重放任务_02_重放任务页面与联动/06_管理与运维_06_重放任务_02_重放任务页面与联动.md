## 2. 任务内容 <a id="content"></a>

1. **创建任务**：表单支持 offset 区间 / 时间区间 / key / 分区（缺省全部分区）/ 速率上限（1~1000 条/秒）；展示范围摘要与预计总量；提交前二次确认（范围、速率、目标消费组）；权限 `msg:manage`。
2. **任务列表**：状态 / 主题 / 时间筛选，分页；列展示状态、进度（已重放 / 总量）、速率、创建时间；点击进入详情。
3. **任务详情**：进度条与数字、首末 `log_id`、错误信息、影响消费组表（基线 / 当前 / 变化）、状态操作按钮（暂停 / 恢复 / 取消）；终态只读。
4. **操作交互**：暂停 / 恢复 / 取消均二次确认；操作后轮询或刷新进度；取消说明“已写入记录不回滚，消费端按 `message_id` 幂等”；失败展示原因。
5. **死信联动**：死信页签“重放”跳转或内联创建单条重放任务，创建成功后死信状态变 `replaying`；死信详情可查看关联 `replay_task_id` 与任务进度。
6. **权限与文案**：查询 `msg:query`，写操作 `msg:manage`；无权限不渲染按钮；所有标题 / 字段 / 确认文案 / 错误码文案入 i18n。
7. **边界**：不做“一键全放”；不在前端计算进度真值；不绕过确认参数；不展示消息正文；不新建第二套重放页面。
8. **测试**：创建 / 列表 / 详情 / 暂停 / 恢复 / 取消交互；影响表字段；死信联动；权限态；错误码展示；原型逐页对照；组件覆盖率 100%。

## 3. 完成标准 <a id="accept"></a>

- 重放任务可创建、列表、详情、暂停、恢复、取消，进度与影响可见；
- 创建与高危操作二次确认展示范围 / 速率 / 目标组，提交带 `confirm=true`；
- 死信重放可从死信页发起并回链任务详情；
- 无 `msg:manage` 不渲染写操作；
- 页面逐页对照原型，组件测试与构建体积门禁全绿，变更模块覆盖率 100%。
