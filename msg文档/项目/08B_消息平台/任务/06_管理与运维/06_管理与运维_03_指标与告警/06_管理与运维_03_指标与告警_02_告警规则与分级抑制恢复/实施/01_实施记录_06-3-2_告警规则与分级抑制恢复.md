## 3. 实施过程 <a id="process"></a>

1. **上下文**：读需求 06-3、架构 06 §8、bms 可观测性设计与部署规范、现有 `bms-slo.yml` / `alertmanager.yml.tmpl` / Grafana provisioning。
2. **决策确认**：分级 / 抑制 / 阈值占位 / 资产落点 / 验证方式逐项确认。
3. **规则**：按故障面分 6 组（availability / lag / errors / dlq / storage / replay），14 条告警；P0/P1 → `critical`、P2/P3 → `warning`，`priority` 保留 P0~P3；每条带 summary / description / runbook / dashboard。
4. **回归文件**：低值序列断言 14 条全部不触发（规则可加载、表达式可求值、不误报）。
5. **看板**：8 个面板（吞吐 / 积压 / 死信 / 磁盘 / 延迟 / 错误 / 饱和度 / 重放），变量 `tenant` / `topic`。
6. **bms 接入**：`prometheus.yml` 加 `msg` 抓取与探针目标、`rule_files` 加 `products/*.yml`；compose 挂载 `observability/products`；Alertmanager 模板加「同实例」与「同主题」两条抑制。
7. **验证**：服务器容器内 `promtool check rules` / `promtool test rules`；渲染 Alertmanager 后 `amtool check-config`；本地静态断言。
8. **文档**：设计对齐、需求注块、计划回写、部署聚合步骤登记。

## 4. 关键实现说明与偏差 <a id="key"></a>

### 4.1 分级与抑制

- P0：`MsgMetricsDown`（`up{job="msg"}=0`）/ `MsgNotReady`（blackbox `/readyz` 失败）。
- P1：积压超阈值 / 积压持续增长 / 发布错误率 > 5%。
- P2：死信增长 / 延迟转投失败 / ISR 收缩（02-5 前恒 0）/ 重放失败。
- P3：磁盘高水位 / 存储拒绝 / inflight 停滞 / 长轮询堆积 / 限流拒绝。
- 抑制：保留原有「critical 抑制同名 warning」；新增「critical 抑制同 service 的 warning」与「P1 抑制同 service+topic 的 P3」；`amtool` 复核为 3 条。

### 4.2 偏差（回写设计）

| # | 设计原写 | 实际 | 原因 |
| --- | --- | --- | --- |
| 1 | receiver 根写 `send_resolved: true` | 由渲染脚本写入 `email_configs` / `webhook_configs` | Alertmanager 的 `send_resolved` 属于渠道配置，receiver 根非法（`amtool` 报错） |
| 2 | 抑制按「P0 抑制 P1/P2」写 | 以 `severity` 为源（critical 抑制 warning）+ 同 service 等价标签 | Alertmanager 不支持按 priority 区间匹配；P0/P1 都是 critical，覆盖目标 |
| 3 | 规则阈值全部可执行 | 占位数值 + `TODO(8B_12)` 行尾标记 | 无容量模型，未实测值不写成结论 |

### 4.3 部署聚合

- 服务器 `~/deploy` 没有 msg 仓；产品资产按「msg 仓自持源文件 → 部署时聚合」：
  - `msg/deploy/observability/rules/msg.yml` → `~/deploy/observability/products/msg.yml`
  - `msg/deploy/observability/grafana/dashboards/msg.json` → `~/deploy/observability/grafana/dashboards/products/msg/msg.json`
- `prometheus.yml` 的 `rule_files` 已加 `/etc/prometheus/rules/products/*.yml`；compose 已挂 `observability/products`。
- 上线顺序：先部署 msg 服务，再把 `msg:8000` 抓取目标加入生产配置；未部署时该 job `up=0` 会触发 P0。
