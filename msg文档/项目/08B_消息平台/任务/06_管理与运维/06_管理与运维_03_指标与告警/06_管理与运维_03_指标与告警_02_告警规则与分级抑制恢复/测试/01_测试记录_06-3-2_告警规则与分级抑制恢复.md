## 4. 覆盖率 <a id="coverage"></a>

本子任务无新增 Python 业务模块；静态断言用例随 `tests/observability/` 纳入改动行判定并通过。规则与看板非代码产物，不参与 Python 覆盖率统计。

## 5. 真机验证口径 <a id="real"></a>

服务器当前只部署 bms 九服务与 mdm，**没有 msg 服务**，因此：

- `up{job="msg"}` 与真实指标触发无法现场验证；
- 本轮以 `promtool test rules`（规则逻辑）+ `amtool check-config`（抑制语法）+ 配置断言作为等价验证；
- 「接入后触发与恢复」登记为**部署窗口待验**，不写成已通过。
