## 2. 任务内容 <a id="content"></a>

1. **h2c 传输**：用 `h2` 库直接实现 HTTP/2 cleartext 连接（不引入 ASGI 框架），客户端 / 服务端共用帧与流管理。
2. **二进制协议**：MessagePack 负载；发布 / 订阅 / ack 三类请求；错误码与版本。
3. **单机 broker**：单 topic / 单 partition / 单消费组；内存队列 + 最小文件日志。
4. **可靠性**：ack、可见性超时、重试、死信；进程重启后恢复。
5. **基准**：与「同逻辑的 HTTP/1.1 + JSON」对比吞吐 / P50 / P99。
6. **测试与文档**：单测 + 集成 + 基准报告；实施 / 测试记录。

## 3. 完成标准 <a id="accept"></a>

- [ ] 发布 → 订阅 → ack 闭环通过。
- [ ] 未 ack 超时重投；重试超限进死信。
- [ ] 进程重启后已确认消息不丢、未确认消息可重投。
- [ ] 基准报告：HTTP/2 + MessagePack vs HTTP/1.1 + JSON 的吞吐 / P50 / P99。
- [ ] 变更模块覆盖率 100%（行 + 分支）。
- [ ] Kiwi 用例登记并标注。
