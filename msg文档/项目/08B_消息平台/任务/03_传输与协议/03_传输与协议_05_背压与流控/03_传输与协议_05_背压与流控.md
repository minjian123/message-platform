## 2. 任务内容 <a id="content"></a>

1. **长轮询**：消费请求挂起直到有消息或 `maxWait` 到期；`maxWait` 默认 **30s**（可配），不得永久挂起。
2. **inflight 双阈值**：单消费者默认 **100 条 / 16 MiB**；超限暂停推送，ack / 超时归还后恢复；阈值可配。
3. **HTTP/2 流控窗口即信用额度**：接收方按已消费字节归还 credit，发送方窗口用尽自动暂停；不另造一套传输层背压。
4. **生产限速**：按租户 / 主题速率配额，超限返回 `350005`；令牌桶或漏桶在详细设计定稿，参数可配。
5. **慢消费者隔离**：单个消费者停止消费时，积压上涨但服务不崩；不得拖垮同连接其它 stream 或其它消费者。
6. **指标**：inflight 用量、窗口暂停次数、限流拒绝计数、长轮询等待数；埋点由本任务提供，指标暴露由 [06-3](../../../需求/06_需求_管理与运维.md#r06-3) 统一。
7. **边界**：磁盘水位归 [02-6](../../../需求/02_需求_存储与复制.md#r02-6)（02 域）、租户配额归 [05-3](../../../需求/05_需求_多租户与安全.md#r05-3)（05 域）、连接上限归 03-4；本任务只做**接入层背压**。
8. **测试**：消费停止 / 恢复、inflight 超限、窗口耗尽、限流拒绝、长轮询到期返回空；不得以单层背压冒充三层。

## 3. 完成标准 <a id="accept"></a>

- 消费停止时积压上涨但服务不崩溃；恢复后继续推送。
- `inflight` 超过条数或字节阈值时暂停推送，归还后恢复。
- h2 窗口耗尽时发送自动暂停，窗口恢复后继续；不出现忙等。
- 生产超限返回 `350005`；长轮询到期返回空而不是永久挂起。
- 慢消费者不影响其它 stream / 消费者的正常吞吐。
- 变更模块行 + 分支覆盖率 100%，静态检查全绿。
