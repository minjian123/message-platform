## 2. 任务内容 <a id="content"></a>

1. **应用层心跳**：`PING` / `heartbeat` 帧，**不得用 TCP keepalive 替代**；心跳与业务处理分离，避免处理慢导致连接被误判死亡。
2. **半开连接判定**：按心跳间隔与超时阈值识别半开连接并释放；空闲连接按空闲超时回收；阈值在详细设计定值并写默认。
3. **GOAWAY 优雅关闭**：停止接新 stream、等待在途完成、超时后强制关闭；与基座信号摘流协同（SIGTERM → `start_drain()` → GOAWAY → drain）。
4. **客户端重连**：交付一个**最小测试客户端**（指数退避 + 抖动）用于验收；正式 Producer / Consumer / RPC 客户端 SDK 归 8B_03，不在本任务扩张。
5. **连接上限**：单连接最大并发流（`MAX_CONCURRENT_STREAMS`）、连接数上限、单连接空闲回收时间；超限返回明确 error，不静默丢弃。
6. **连接元数据**：协议版本、租户、客户端地址、建立 / 关闭原因可观测；为排障与 06 域指标提供输入。
7. **滚动重启**：GOAWAY 后客户端可重连到新实例，在途请求不丢；重连不得形成脉冲（退避 + 抖动）。
8. **边界**：不做认证与授权（05 域）、不做背压与限速（03-5）、不做客户端选实例 / 负载均衡（8B_03 / 8B_05）、不做连接池（8B_03）。

## 3. 完成标准 <a id="accept"></a>

- 网络中断后连接在超时内被识别并释放；不会长期占用资源。
- 滚动重启（GOAWAY）不丢在途请求，客户端能自动重连。
- 重连带指数退避 + 抖动，不形成连接脉冲。
- 单连接并发流 / 连接数超限时返回明确错误；连接元数据可查。
- 心跳与业务处理互不阻塞（慢业务不触发误判）。
- 变更模块行 + 分支覆盖率 100%，静态检查全绿。
