## 2. 策略与范围 <a id="scope"></a>

| 层 | 验什么 | 不验什么（归口） |
| --- | --- | --- |
| 内容类型 | 缺省值、已知取值、未登记透传、语法非法、大小写与参数截断 | 各格式的真实反序列化（SDK / 业务） |
| 压缩 | 标记与算法自洽、白名单、上限判压缩后字节、生产者压→broker 原样→消费者解 | 真实算法库的压缩比与性能（8B_03 / 平台级容量实测） |
| 直通 | 帧路径 payload 零 base64（发布侧与消费侧）、JSON 路径保留 base64、上限同一判据 | 大消息内存占用实测（平台级容量实测） |
| 校验失败 | `nack` 转死信 + 位点前移、幂等、边界码、死信原因与详情 | 校验器真实调用方与 schema 定义（8B_03） |
| 出口一致 | 帧头 `messages[i]` / JSON `MessageItem` / SSE `message` 三处回显 | 前端与 SDK 的展示形态（8B_03） |
| 契约 | `frame_media_type` 改名、三组新键、`5: nack`、预留区间 `6-15` | 跨仓 SDK 生成（8B_03） |

| # | 现象 | 归因 | 处置 |
