## 4. 实测口径 <a id="measure"></a>

| 项 | 口径 |
| --- | --- |
| 退避用例 | 注入 `jitter=lambda low, high: low`，等待取下界（0.5/1/2.5/5/15/30s），断言 `next_attempt_at` 与「未到点不重试」 |
| 存量退避适配 | `test_delay_disposal` 初始 attempts=3 → 下一次基础退避 10s，推进 5s；`test_watermark` 第二次失败推进 1s |
| 中间件 | 直接构造 ASGI scope / receive / send，不启动真实服务；断言下游是否被调用、响应状态与 body |
| 采样隔离 | 直接调 `_sample_lag` / `_sample_dlq`，用会话 / 消息 / 死信替身控制单主题失败；日志用 `capture_logs()` 捕获事件名 |
| 配额字节 | 直接调 `_payload_bytes` + `_ensure_storage_quota`，配额 / 用量用替身；monkeypatch `resolve_payload` 计数解码次数 |
| 毒消息 | 真实 `DeliveryService` + 内存存储 / 位点 / 死信；用同 key 锁定同分区；重建 `DeliveryService` 模拟复跑 |
| 契约 | `ops.contract_snapshot export` + `generate.mjs`，差异仅 payload `maxLength` 与 description |
