## 4. 实测口径 <a id="measure"></a>

| 项 | 口径 |
| --- | --- |
| 采样注入 | 用例注入 `usage(path) -> (total, used, free)` 与单调假时钟；`total=1000` 时 `used` 直接读作千分比，阈值断言可写成精确值 |
| 水位阈值 | 用例显式传 `warn_ratio` / `reject_ratio` / `ttl_ms`，**不吃环境变量**（避免同机环境差异）；环境变量路径另用 `monkeypatch.setenv` 单独验 |
| 目录不可写 | 不用 chmod（Windows 无等价语义），而是把数据根做成**普通文件** → `mkdir` 必失败 |
| 祖先耗尽 | 不用「不存在的盘符」（Windows-only），而是 `monkeypatch` 让 `Path.stat` 恒抛 `FileNotFoundError` → 上溯到根后抛出 |
| 日志断言 | 替换模块级 `_LOGGER` 为记录器（结构化事件名 + 字段），不解析渲染文本 |
| 转投失败 | `monkeypatch` 把存储的 `append` 换成抛 `OSError(ENOSPC)`；时间轮与调度器共用同一 `now`（否则命中回拨分支） |
| 发布拒绝 | 走真实 `DeliveryService` / `DelayService`（请求级主题仓储 + 内存存储），断言 `LEO` 与延迟区条目数证明「没有写入」 |
