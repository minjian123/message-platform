## 1. 现状事实 <a id="facts"></a>

| # | 事实 | 位置 | 后果 |
| --- | --- | --- | --- |
| 1 | 拓扑值对象只有副本集、最小同步副本数、任期、leader、切换状态，**没有主题身份** | `broker/replication.py` `PartitionTopology` | 协调器拿不到租户 / 命名空间 / 主题名，审计无处落 |
| 2 | 加载器只查分区行，主题身份未取 | `services/replication_topology.py` `_topic_rows` / `load` | 同上；联查要落在同一缓存里，否则每轮重建多一次查询 |
| 3 | 主题仓储是租户作用域，后台无请求上下文时默认查询会追加当前租户条件 | `repositories/topic.py` `tenant_scoped = True` | 直接查会查不到；已有 `get_by_id_unscoped` 可绕开作用域 |
| 4 | 协调器装配未注入审计出口 | `main.py` 构造 `ReplicationCoordinator` | 重建只有结构化日志与指标，事后查不到 |
| 5 | 审计动作按 `ACTION_CLASSES` 登记，helper 为 `emit_sensitive`（敏感类，强审计时失败即抛） | `audit/trail.py` | 新增动作必须同时登记分类，否则按默认类别处理 |
| 6 | 运行态快照无状态字段；远端解析在协议版本一致的前提下按键取值 | `ReplicationSnapshot`、`api/internal/schemas.py` `SnapshotResponse`、`broker/network.py` 远端解析 | 加字段要三处同步，否则远端读不到 |

## 2. 已确认口径 <a id="decisions"></a>

| # | 口径 | 结论 |
| --- | --- | --- |
| 1 | 租户上下文来源 | **拓扑补租户三字段**（租户标识 / 命名空间 / 主题名），加载器同缓存带回 |
| 2 | 审计时点 | **成功 + 转人工两态**；失败重试只走日志与指标 |
| 3 | 契约范围 | **内部快照与管理面同时暴露**，两处重导 |
| 4 | 字段类型 | **五值闭集** |
| 5 | 审计强弱 | **普通审计**（写失败只告警，不阻断重建） |

第 5 条与第 3 条口径（拿不到租户不写审计）自洽：审计既然可以因上下文缺失而跳过，就不能反过来挡住建库动作。

## 3. 拓扑携带主题身份 <a id="topology"></a>

`PartitionTopology` 增三个带默认值的字段，既有构造点（配置兜底与用例）不需要改：

| 字段 | 类型 | 默认 | 语义 |
| --- | --- | --- | --- |
| `tenant_id` | `int` | `0` | 主题所属租户主键（0 = 未知，审计不写） |
| `namespace` | `str` | `""` | 命名空间（审计作用域第二级） |
| `topic` | `str` | `""` | 主题名（审计作用域第三级） |

加载器改法：`_topic_rows` 顺带取一次主题行（`TopicRepository.get_by_id_unscoped`），与分区行**同一次会话、同一条缓存**（缓存值由「时刻 + 分区行」扩为「时刻 + 分区行 + 主题身份」）。`load` 命中分区行时把身份一起塞进拓扑；主题行取不到（已删 / 清理中）时三字段留默认值，复制行为不变。

不改缓存 TTL 语义：身份与分区行同时过期，避免出现「分区分配已更新、租户还是旧的」这类撕裂。

## 4. 重建审计 <a id="audit"></a>

**动作登记**：`audit/trail.py` 增 `PARTITION_RESYNC_ACTION = "msg:partition.resync"`，进 `__all__`，并在 `ACTION_CLASSES` 登记为敏感类、**非强审计**、标签「分区重建」。

**两个时点**（同动作、以参数 `phase` 区分）：

| 时点 | 触发条件 | 参数 |
| --- | --- | --- |
| 成功 | `reset_to` 成功、状态转「追赶中」 | `phase=succeeded`、主题主键、分区号、leader、leader 起点、丢弃条数、耗时毫秒 |
| 转人工 | 连续失败达上限、状态转 `blocked` | `phase=blocked`、主题主键、分区号、累计失败次数、最后一次原因、leader 起点 |

**定位**：`method="POST"`、`path="/internal/msg/partition/resync"`（与切主审计同样的写法：不是 HTTP 端点，只用于审计定位）。

**写入失败处置**：`emit_sensitive` 走普通审计分支，失败只记一条告警日志，重建继续。**无租户上下文**（`tenant_id <= 0` 或命名空间 / 主题名为空）时**不调用**审计 helper，改为记一条带原因的告警日志，绝不写零租户伪审计。

**装配**：`ReplicationCoordinator` 增可选构造参数 `audit`（默认 None = 不写审计，用例与进程内复用不必改），`main.py` 传入既有 `sink`（该实例在协调器构造之前已就绪）。

## 5. 状态字段 <a id="state"></a>

五值闭集沿用 02-11 已定义常量：`in_sync` / `diverged` / `resyncing` / `catching_up` / `blocked`。

**三处投影**：

| 位置 | 改法 | 说明 |
| --- | --- | --- |
| `ReplicationSnapshot` | 增 `resync_state`，默认 `in_sync` | 运行态单一数据源 |
| 内部快照响应 | 增同名字段，默认 `in_sync`；解析时按键取值 | 协议版本不变：老节点不发该字段时按正常处理，**该字段不参与任何判定**，只作观测 |
| 管理面分区列表 | `PartitionView` 与 `PartitionItem` 增同名字段 | 复制关闭时也返回该值（恒为正常），避免可空语义 |

闭集的表达方式：契约模型上用枚举约束（生成器据此产出联合类型），不改 `switch_state` 的现状（那是 02-5 已上线的自由字符串，本轮不动，避免捆绑契约变更）。

## 7. 用例矩阵 <a id="cases"></a>

| # | 场景 | 断言要点 |
| --- | --- | --- |
| 1 | 重建成功写审计 | 一条审计落库，参数含丢弃条数与起点；动作可检索 |
| 2 | 转人工写审计 | 达上限转 `blocked` 时一条审计，参数含累计失败次数 |
| 3 | 失败重试不写审计 | 中间失败只增指标，审计条数为 0 |
| 4 | 无租户降级 | 拓扑身份为空时不写审计、有告警，重建照常成功 |
| 5 | 审计写失败不阻断 | 审计出口抛错，重建仍成功、状态仍转追赶中 |
| 6 | 拓扑携带身份 | 加载器返回的拓扑三字段与主题行一致；主题行缺失时为默认值 |
| 7 | 缓存同源 | 分区行与身份同一次加载、同时过期 |
| 8 | 状态字段投影 | 内部快照与管理面都返回五值之一；重建各阶段取值正确 |
| 9 | 远端缺字段兼容 | 响应体不含该字段时按正常处理，不报错 |
| 10 | 回归 | 02-11 的重建追平 / 幂等 / 转人工三态仍通过 |

## 8. 不变量 <a id="invariants"></a>

- 审计**永不改变**重建的成败判定与状态流转顺序；
- 无租户上下文时**不产生**任何租户标识为零的审计记录；
- 状态字段**只读**：不参与可写判定、不参与选主、不影响拉取节奏；
- 契约里状态取值是闭集，出现未登记值即为缺陷（解析失败优于静默接受）；
- 拓扑身份与分区分配**同源同缓存**，不出现身份与分配来自不同快照的情况。

## 9. 风险与对策 <a id="risk"></a>

| 风险 | 对策 |
| --- | --- |
| 审计写失败导致重建卡住 | 普通审计，失败只告警；不变量第 1 条约束 |
| 滚动升级期老节点不返回状态字段 | 默认按正常处理；字段只作观测，不影响判定 |
| 主题行已删导致审计缺口 | 无租户时降级告警，重建继续；缺口可经指标统计 |
| 闭集后续扩值需要改契约 | 有意为之：扩值走契约变更评审，避免前端静默接受未知值 |

## 10. 实施口径回写（2026-11-16） <a id="asbuilt"></a>

实施后与本设计不同的两处，以本节为准：

| # | 设计原文 | 实施口径 | 原因 |
| --- | --- | --- | --- |
| 1 | 转人工审计参数含「最后一次原因」 | 运行态增 `resync_last_reason`，失败时暂存、成功后不落审计 | 原因只在异常处理块内可得，审计发生在状态翻转处，须由运行态传递 |
| 2 | 未涉及测试范围 | 另补两个既有分支用例（审计同事务写入优先、重建成功但未装配唤醒器） | 选测范围收敛后这两个分支不在本轮选中文件内，模块级 100% 会掉；补的是既有行为断言，不改实现 |

其余口径与设计一致：身份与分区行同缓存、成功与转人工各一条审计、非强审计、五值闭集三处投影、契约两处重导。
