## 1. 域说明 <a id="intro"></a>

本域对应需求 [02 存储与复制](../../需求/02_需求_存储与复制.md)，承载消息平台的存储地基：分区追加日志、崩溃恢复、消费位点、ISR 复制、选举与故障切换、存储水位、延迟消息持久化与到期恢复。

任务按「一个可独立验收的交付单元」拆分，与需求 02-1~02-7 **一一对应**（任务编号即需求编号），跨文档引用直接复用。存储层任何缺陷都是数据丢失级别，本域任务一律以「可复现故障注入 + 崩溃语义可断言」为验收基线。

**阶段分工**：02-1、02-2、02-3、02-6、02-7 归 **8B_02**；02-4、02-5 归 **8B_05**。原「全部任务以 **8B_01（传输与协议 PoC，go/no-go）** 为前置」**已于 2026-11-05 满足**——8B_01 门禁 2 判「已达成」（03 域 03-1~03-5 收口），02-1 / 02-2 / 02-3 / 02-6 / 02-7 **解除搁置**（状态与窗口由阶段计划承载，本域不填日期、不写窗口）；02-4 / 02-5 仍按 8B_04 / 8B_05 搁置。进度与窗口见阶段计划。

文档格式依 bms《[任务文档规范](../../../../../bms文档/规范/任务文档规范.md)》。

## 3. 依赖与风险 <a id="dep"></a>

| 项 | 说明 |
| --- | --- |
| 上游依赖 | **8B_01 传输与协议 PoC——已达成（2026-11-05，门禁 2）**：03 域 03-1~03-5 全部交付；01 域已交付的 `MessageStore` / `DelayStore` / `OffsetStore` 端口与组协议（**端口签名不变**，本域只换实现；03-3 / 03-5 已把签名定死，见各任务的前置回写） |
