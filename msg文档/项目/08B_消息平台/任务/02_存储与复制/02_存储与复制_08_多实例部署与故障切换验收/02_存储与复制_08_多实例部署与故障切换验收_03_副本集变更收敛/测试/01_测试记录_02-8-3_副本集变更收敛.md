## 2. 分组与覆盖 <a id="groups"></a>

| 组 | 覆盖点 | 例数 |
| --- | --- | --- |
| G1 缩容 | 三 → 两节点：`replicas` / `followers` / `ISR` 同步剔除，指标行 `isr_size=2` | 1 |
| G2 扩容 | leader 侧新成员按日志起点建进度、`in_sync=False`、暂不进 ISR；follower 侧只更新集合；非承载占位由挂载轮替换为承载态（真机暴露回归） | 3 |
| G3 本节点被移出 | `hosted=False`、退出 `mounted_partition_keys()`、已挂载数减一、指标行删除、`pull_round()==0`；重复卸载返回 False；非承载态卸载不减计数 | 3 |
| G4 幂等与中间态 | 同集合重复刷新不动进度对象；先扩后缩各收敛一次、ISR 轨迹 2→2→2 | 2 |
| G5 脏 leader | leader 不在新集合：保留 leader 与角色、整轮不收敛 | 1 |
| G6 交集成员 | 新增成员时原成员 `FollowerProgress` 对象与位点不重置 | 1 |
| G7 HW 重算 | 剔除落后成员后 HW 推进且唤醒长轮询（waiter 版本自增） | 1 |
| G8 单实例零变化 | 复制关闭时刷新不进收敛路径、副本集不随库变化 | 1 |
| 边界 | 历史行 `replicas` 为空不据以收敛；卸载不删本地数据（LEO / 起点不变）；计数自减有下限 | 3 |
