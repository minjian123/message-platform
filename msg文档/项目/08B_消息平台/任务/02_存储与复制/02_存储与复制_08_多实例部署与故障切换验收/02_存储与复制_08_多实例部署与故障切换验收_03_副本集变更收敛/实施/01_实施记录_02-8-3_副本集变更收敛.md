## 5. 实现要点 <a id="impl"></a>

| 点 | 说明 |
| --- | --- |
| 收敛入口 | `_observe_topology` 先比 `topology.replicas != state.replicas`（内容比较，`ConcurrentStableFrozenList.__eq__` 按序比元素）；相等即沿用既有 epoch / leader / switch 收敛，零额外开销 |
| 三态返回 | `applied`（继续后续字段）/ `detached`（已卸载，本轮到止）/ `invalid`（脏 leader，整轮到止）。**不能只用布尔**：脏数据时若继续走 `_apply_leader_change`，会把不在副本集里的 leader 应用到运行态 |
| 卸载 | 取 `_attach_lock` 后从 `_partitions` 弹出并置 `hosted=False`；清 `_fetch_backoff` / `_fetch_backoff_delay` / `_fetch_failure_logged_at` / `_fetch_due_at` / `_idle_streak` 五个键；`metrics.forget` + （原先计入时）`unrecord_mount` |
| 指标不回潮 | `_update_metrics` 对「复制开启且非承载」的分区只删行不写行——卸载时在飞的拉取收尾不会再补回旧行 |
| 新成员 | 进度取 `store.start_offset`、`last_fetch_ms=now`、`in_sync=False`；由既有扫描路径在追平后重入 ISR，不改判据 |
| HW | 剔除成员后 `ISR` 只可能变小，`min(leader LEO, ISR follower LEO)` 只可能不变或变大，故仅 leader 侧调 `_advance_hw`（推进即唤醒长轮询） |
| 幂等 | 以「当前 DB 副本集」为准而非台账状态：`expand` / `shrink` 两次写库各收敛一次，重复观察同集合不动作 |
