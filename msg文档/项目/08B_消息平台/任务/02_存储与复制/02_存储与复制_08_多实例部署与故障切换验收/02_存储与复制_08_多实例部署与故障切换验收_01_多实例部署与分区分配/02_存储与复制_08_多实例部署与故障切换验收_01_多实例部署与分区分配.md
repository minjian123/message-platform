## 2. 任务内容 <a id="content"></a>

1. **拓扑与编排**：N 实例（至少三实例）容器编排，端口、数据卷、位点卷按实例隔离；实例加入平台 Docker 网络，服务目录可发现。
2. **副本配置**：`replication_factor`、`min.insync.replicas`、`acks` 档位可配；单实例模式（`replication_factor=1`）行为与 8B_02 完全一致，可随时回退。
3. **分区分配**：分区按副本分配到实例；新实例加入 / 下线时的分配结果可核对（分区 → leader / followers），分区数只能增不能减。
4. **副本迁移**：实例下线前把分区副本迁移到健康实例；迁移期间写入不中断或按设计降级，迁移完成后 ISR 恢复。
5. **客户端配置**：客户端实例列表从「一个地址」扩为「一组地址」，与 04-6 的 `InstanceProvider` 口径一致；地址变更只改配置。
6. **可观测**：ISR、HW、leader、副本延迟、迁移进度可查；迁移与分配事件留结构化日志。
7. **测试**：多实例编排解析、副本分配断言、加入 / 下线迁移用例、单实例回退回归。

## 3. 完成标准 <a id="accept"></a>

- N 实例拓扑可部署、可回退单实例，端口与卷隔离正确；
- 分区分配与副本迁移结果可核对，迁移期间不丢已提交消息；
- 客户端实例列表可配置，地址变更不改代码；
- ISR / HW / leader / 副本延迟 / 迁移进度可观测；
- 变更模块行 + 分支覆盖率达标，静态与文档校验通过。
