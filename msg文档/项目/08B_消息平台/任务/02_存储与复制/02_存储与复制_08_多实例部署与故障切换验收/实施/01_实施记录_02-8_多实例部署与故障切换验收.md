## 3. 关键实现口径

1. **单实例零变化**：内部端口缺省 0，不监听、不建内部应用；传输仍用进程内实现；`replicas=[]`。
2. **fail-closed**：多实例缺内部端口 / 端点覆盖不全 / 端口与业务端口相同 / 令牌签发者不可用 → 启动失败。
3. **分配单一实现**：建主题、增分区、`ops.rebalance` 共用 `PartitionAssigner`；与 02-4 配置兜底同算法，升级不改既有分配。
4. **迁移先扩后缩**：`replace` 在同一台账行按 `step=expand → shrink` 推进；移除 leader 前先切主；追平判据为「目标在 ISR 且 LEO ≥ leader HW」。
5. **降级不计通过**：`force` / `isr_verified=false` 落 `degraded` 并写原因；状态命令与演练结论都不得写成「通过」。
6. **台账可续跑**：`planned/running/catching_up` 均可被 `apply --resume` 接续；CAS 条件更新 + 版本号防并发。
7. **演练单源扩 `target`**：本机六类 `local`、多实例三类 `docker`；`ops.drill run` 拒绝 docker 场景，`ops.cluster_drill` 只跑三类。
8. **客户端刷新**：`350033` → 读 `metadata_version` / `leader` / `epoch` → 改投；首期只验服务端语义，SDK 归 8B_03。
