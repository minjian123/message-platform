## 2. 用例清单 <a id="cases"></a>

| # | 用例 | 关键断言 |
| --- | --- | --- |
| 1 | 租约可见性 | A 持租约时 B 的 `list_active` 不含该任务；同一持有者始终可见 |
| 2 | 租约过期 | 时钟推进超过租约后 B 可取到该任务 |
| 3 | 抢占排他 / 续约 | B 抢占失败；A 可重复抢占并推进到期时间 |
| 4 | 让出 | 租约被接管后 `update_owned` 返回 None，进度不被旧持有者覆盖 |
| 5 | 多实例推进 | A 推进后 B 本轮写入 0（未重复 `append`） |
| 6 | 崩溃接管 / 重启续跑 | 租约过期后 B 接管并跑完；终态 `lease_owner` / `lease_expires_at` 为空 |

| 18 | 哈希碰撞 | 恒定哈希下按候选回读比对，返回正确记录 |

## 4. 覆盖范围说明 <a id="scope"></a>

- 租约与概览用例使用内存 SQLite 与真实仓储；多实例通过「同一会话 + 不同 owner / 时钟」模拟，不启真容器。
- 死信「跨实例」用两个队列实例共享同一 DB 会话模拟。
- `log_id` 磁盘索引覆盖「重启 / 卸载 / 缺索引重建 / 哈希碰撞」，不覆盖 4 GiB 以上索引文件的分块读取（实现按整文件读取，单分区百万级约 16 MB）。
- 概览接口读库分支由 API 用例覆盖；采样器写库分支由服务用例覆盖。
