## 2. 任务内容 <a id="content"></a>

质量盘点「多实例一致性缺口」盘点2 / 盘点3 / 盘点4 / 盘点5 / 盘点9 已交付承诺里写明「归 02-8」，但一直未做。本任务一次补齐六项：

1. **重放任务租约**（盘点2）：`msg_replay_task` 增 `lease_owner` / `lease_expires_at`；执行器每拍先 CAS 抢 / 续租约，只推进自己持有的任务；租约过期可被其他实例接管，重启后未完成的任务自动续跑（顺带补 F2「重启不续跑」）。
2. **死信索引 DB 权威**（盘点3）：`contains` 以 `msg_dead_letter` 唯一三元组为准，进程内只保留 5 秒短缓存（有界）；其他节点转入的死信最长 5 秒后在本节点生效。
3. **主题缓存 TTL**（盘点4）：进程内主题快照加 5 秒 TTL，本实例写操作仍立即失效；其他实例的停用 / 删主题 / 改保留期最长 5 秒收敛，不再永久按旧值放行。
4. **概览快照落库**（盘点5）：新增 `msg_overview_snapshot`（每租户一行），采样器周期覆盖写；`/admin/overview` 优先读该行，读不到才回退进程内快照（单实例 / 冷启动兼容）。
5. **入口速率跨实例**（盘点5）：新增 `msg_ingress_counter`（租户 × 时间窗，按增量累加）；采样器每拍把本实例增量写入 DB，概览按最近若干窗口求和换算速率，多实例不再各报一份。
6. **`log_id` 持久化索引**（盘点9）：每个分区目录新增 `log_id.idx`（哈希 + offset 的定长条目），写入时同步追加；冷记录 / 重启后仍可定位，不再只依赖进程内 LRU 与已加载段头。

**边界**：不新增外部依赖（不引入 Redis / 消息总线）；不做跨实例失效广播（TTL 收敛即可）；不做位点（盘点6）、inflight / 投递状态（盘点7）、RPC 幂等去重（盘点8）、并发 `create_all`（盘点10）——这些需要存储层或部署层改造，另行立项。

## 3. 完成标准 <a id="accept"></a>

- 同一重放任务不会被两个实例同时推进：未持租约或租约未过期的实例跳过；持租约实例每拍续约；实例崩溃后租约到期，其他实例接管并从未完成的游标继续。
- 死信判定跨实例一致：A 节点转入死信后，B 节点最长 5 秒内判定为已死信，不再重投；本节点新增死信立即可见。
- 主题元数据跨实例收敛：A 节点停用 / 删除主题后，B 节点最长 5 秒内按新状态拒绝写入；本节点写操作仍立即失效。
- 概览数字跨实例一致：任一实例读 `/admin/overview` 都得到同一份每租户快照；入口速率按租户时间窗累加，多实例不重复也不遗漏；重启不清零（采样周期内恢复）。
- `log_id` 重启后可查：新增记录在进程重启、LRU 清空后仍能通过 `find_by_log_id` / `located_by_log_id` 定位到原分区与 offset；未加载分区可通过索引文件定位。
- 变更模块行 + 分支覆盖率 100%；ruff / pyright / 裸集合护栏 / 文档三项 / 契约零漂移全绿。
