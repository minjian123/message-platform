## 4. 实测口径 <a id="measure"></a>

| 项 | 值 | 说明 |
| --- | --- | --- |
| 新增 / 适配用例 | 73（43 + 6 + 5 + 12 + 7） | 单文件运行均 < 2s |
| 定向选测 | 2 230 passed / 177 文件 / 60.5s | `--changed-from 090b5d4`，1 轮扩圈 |
| 两节点簇 | 两个真实 `InMemoryMessageStore` + `InProcessReplicaTransport` | 不做网络与部署变量，只验机制 |
| ISR 阈值 | 时间 10 000ms / 条数 10 000（缺省） | 用例注入可推进时钟做确定性判定 |
| 提交等待缺省 | 5 000ms | 用例缩到 5~100ms |
| 拉取周期 / 批量 / 扫描 / TTL | 200ms / 100 / 1 000ms / 5 000ms | 配置键与缺省值见设计 §12 |
| 指标基数上限 | 500 分区 | 超出不输出 + 一次性 warning |

**机制层面的关键断言**（不是文档承诺）：

1. **HW 只在 ISR 确认后推进**：follower 上报 `from_offset` 前，leader 的 HW 不动（`test_hw_advances_only_after_follower_reports_leo`）；
2. **未提交即不可读**：`_collect` 的读取上限夹到 HW，且 `committed >= HW` 时**不调用 `fetch`**（`test_committed_at_hw_returns_empty_without_fetch`）；
3. **`acks=all` 的两种失败**：ISR 不足立即 `350032`；等待期间收缩也在唤醒后立即返回，不拖到超时；
4. **epoch 双向校验**：follower 拒低任期批次，leader 拒高于本地任期的拉取请求；
5. **关闭态零变化**：`hw == leo`、`visible_limit=None`、`acks=all` 不预检不等待。
