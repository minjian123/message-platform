## 2. 任务内容 <a id="content"></a>

1. **副本模型**：每分区 `replication_factor` 与 `min.insync.replicas` 可配；ISR 集合由 leader 维护；单实例模式（8B_02 阶段）默认 `replication_factor=1`，复制实现可关闭且行为与无复制完全一致。
2. **副本拉取**：follower 按 `(offset, epoch)` 从 leader 拉取记录；leader 记录各副本 LEO；拉取失败按退避重试，不阻塞写入主链路。
3. **提交语义**：leader 本地 append + ISR 副本确认后推进 HW；`acks=all` 要求 `|ISR| >= min.insync.replicas`，不足即**拒绝写**（错误码在详细设计定稿并登记，**不复用 `350005` 磁盘满语义**）。
4. **可见性**：消费者只能读到 `offset < HW` 的消息；未提交部分对消费不可见；HW 随 ISR 收敛推进。
5. **ISR 收缩与重入**：落后超过 lag 阈值（时间 / 条数，详细设计定值）踢出 ISR；恢复后按条件重新加入；收缩 / 重入必须可观测（指标由 [06-3](../../../需求/06_需求_管理与运维.md#r06-3) 接）。
6. **记录字段**：使用 02-1 预留的 `epoch` / 副本位点 / 段级校验；不新增记录格式版本，不改头体分离与 CRC 口径。
7. **部署前置**：多实例拓扑、分区分配与迁移（架构 08 §11 #5）；本任务交付可开关的复制实现与配置口径，单实例不启用。
8. **边界**：不做跨机房强一致、不做 Raft 多数派（架构 04 §7）；不做自动选主（02-5）；不做跨租户共享副本；不做备份（副本不是备份，架构 08 §6）。

## 3. 完成标准 <a id="accept"></a>

- 单副本故障时，已提交（HW 之前）消息不丢；未提交部分允许回退且可说明。
- ISR 收缩与恢复可观测；副本不足时按配置拒绝写而非静默降级。
- `acks=all` 与 `acks=1` 的行为差异有契约用例；消费端读不到 HW 之后的消息。
- 单实例模式回归全绿：复制关闭时行为与 8B_02 完全一致。
- 变更模块行 + 分支覆盖率 100%，静态检查全绿。
