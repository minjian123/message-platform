## 2. 实现清单 <a id="impl"></a>

### 2.1 抽象与值对象（bms `msgclient/instances.py`）

- `InstanceStrategy`（`round_robin` / `least_inflight`）、`InstanceOutcome`（`success` / `failure` / `neutral`）；
- `InstanceSnapshot`（`pool_key` / `addresses` / `revision` / `fetched_at_ms` / `stale`）、`InstanceLease`（`origin` / `revision` / `probe`）、`InstancePolicy`（策略 + 失败阈值 + 摘除 TTL + 快照 TTL + 半开探测数，构造期校验）、`InstanceEntryView` / `InstancePoolView`（用例与排障快照）；
- `InstanceProvider`（`resolve(service) -> InstanceSnapshot`）与 `InstanceSelector`（`acquire` / `report` / `release` / `snapshot`）分离；`StaticInstanceProvider` / `StaticInstanceSelector` / `selector_for()` 提供迁移便捷入口；
- 内部异常 `InstanceUnavailable`（`BizError`，`code=0`，带 `pool_key` / `reason`）。

### 2.2 目录来源与配置（bms `msgclient/adapter/instances.py` + `core/*`）

- `ServiceCatalogInstanceProvider`：`[service_client].instances.<key>` > `endpoints.<key>` > `base_url_template`；映射精确 → `*` → 缺省 `msg`；TTL 内缓存、地址变化 `revision += 1`；
- `normalize_service_instances`：服务键去空白、地址去尾斜线并按插入序去重、显式空列表与非 `http(s)` 地址 `ConfigError` 拒启；
- `ServiceClientSettings.instances` 新字段（`ConcurrentStableDict[str, ConcurrentStableList[str]]`），装配期同 `endpoints` 一起校验；
- 装配：`MsgServiceClientFactory.create()` 构造 `ServiceCatalogInstanceProvider` → 启动期 `resolve(MSG_ENDPOINT_KEY)` 做配置校验 → `selector_for(provider, policy=msg_instance_policy(settings))`；
- `msg_instance_policy`：读 `[service_client].options.instance_strategy`，缺省 `round_robin`，非法值 `ConfigError`；
- `msg_base_url` 改为复用 `msg_instance_addresses(settings)[0]`（事件发布侧多实例取首个，LB / 故障切换归 8B_04）。

### 2.3 换实例与传输层阶段（bms `msgclient/rpc.py` + `transport/*`）

- `RpcClient` 构造破坏性改为 `RpcClient(selector, ...)`；
- 每次尝试一个租约：成功 `release(lease, SUCCESS)`；失败先 `release(lease, outcome)` 再判重试；
- `exclude` 在本次调用内累积（刚失败实例优先跳过）；`preferred` 只在「可能已执行」时设置，下一次 `acquire` 回到原实例，原实例不可用即上抛、不换其他实例；
- 半开探测（`lease.probe`）失败直接上抛，不再消耗重试预算；
- `RpcTransportClosedError.phase`（`connect` / `send` / `await_headers` / `read_body` / `reset` / `unknown`）+ `may_have_been_sent`；`H2Transport` / `H2ClientConnection` / `H2Stream` 各抛出点标注，默认 `unknown` 保守不换；
- `InstanceUnavailableError(RpcCallError)`：`code=0`、`retryable=True`、`category=transient`，不新增产品码。

### 2.4 流式接入（bms `msgclient/stream.py`）

- `RpcStream` 构造改为 `selector` + `request_factory`，构造时不发请求；
- `_open()` 才 `acquire` + `request_factory(lease.origin)` + `open_stream`；
- 打开成功 `report(SUCCESS)`、失败 `release(FAILURE/NEUTRAL)` 并归还在途；流中错误不摘除实例；
- 租约在流正常结束 / `aclose` / 异常退出时释放（幂等，`_lease_released` 标志）。

### 2.5 观测与常量

- 四个结构化日志事件：`msg_rpc_instance_selected` / `removed` / `recovered` / `unavailable`（指标出口归 06-3）；
- 缺省值入 `msgclient/constants.py`：失败阈值 3、摘除 TTL 30s、快照 TTL 30s、半开探测 1。

### 2.6 msg 仓跨仓用例

- `test_instance_failover_contract.py`（4 例）：连接失败切到真 msg 应用（处理器只执行一次）、结果未知（`350004` / `unknown`）留在原实例（真应用处理器从未被调用）、目录为空 `InstanceUnavailableError`、单实例走同一抽象。

## 3. 关键行为口径 <a id="behavior"></a>

| 场景 | 行为 |
| --- | --- |
| 轮询 | 按插入序游标，确定性；`exclude` 优先跳过；单实例被 `exclude` 时允许回退（不能「失败一次就再也打不到」） |
| 最少在途 | 取 `inflight` 最小者，平局按轮询游标顺序，并推进游标 |
| 摘除 | 连续失败达阈值；成功清零；中性不计数（半开探测遇中性按探测失败续摘） |
| 半开 | 摘除 TTL 到期后放 1 个 `probe` 租约；其余请求在探测在途时快速失败（`probe_in_flight`） |
| 全部摘除 | 有到期半开实例 → 放一个探测；都在 TTL 内 → `all_evicted`；探测已占满 → `probe_in_flight` |
| 换实例 | 仅 `phase ∈ {connect, send}`、限流拒绝、服务端 `transient` 且 `retryable`；其余同实例重试 |
| 快照变化 | 按 `revision` 保留交集 origin 状态、删除消失 origin、新增默认健康，游标取模 |

## 4. 实施中的口径修正 <a id="corrections"></a>

| # | 事项 | 处置 |
| --- | --- | --- |
| 1 | 「可重试错误换实例」无法区分「请求是否已发出」 | 传输层增 `phase` + `may_have_been_sent`，换实例收敛为「确定未执行」；默认 `unknown` 保守不换 |
| 2 | 单实例被 `exclude` 后无可选实例 | `acquire` 允许回退到被排除但健康的实例；多实例时仍优先其他健康实例 |
| 3 | 不可用原因无法区分 | `acquire` 区分 `empty_snapshot` / `preferred_unavailable` / `all_excluded` / `all_evicted` / `probe_in_flight` |
| 4 | 集合声明受基座「裸集合护栏」约束 | selector / provider 内部状态与快照改用 `ConcurrentStableDict` / `ConcurrentStableList` / `ConcurrentStableFrozenList` / `ConcurrentStableSet`；测试断言用 `tuple(...)` / `list(...)` |
| 5 | 配置校验时机 | 工厂构造时 `resolve` 一次，把「模板缺 `{service}` / 空列表 / 非法地址」在装配期暴露为 `ConfigError`，不推迟到首次调用 |
| 6 | **全量预检首次暴露 `msgclient` 23 处基类继承违规**（17 处为 `06_01` 存量，当时提交环只选了 msgclient 用例、未跑到全量护栏） | 按铁律全量归位：值对象 → `BaseValueObject`（frozen）、可变状态 → `BaseDataContract`、行为类 → `BaseFrameworkObject`、异常 → `BizError`；新增 `test_protocol_base_inheritance.py` 固定形态；另一次 `fix(bms-core)` 提交 |
| 7 | 异常归位不能改变捕获语义 | `RpcCallError` / `RpcRetryBlockedError` / `RpcTransportError` / `InstanceUnavailable` 仍为 `Exception`，`code` / `message` / `str()` 不变；`to_bms_error` 与 msg 侧捕获路径零改动 |
