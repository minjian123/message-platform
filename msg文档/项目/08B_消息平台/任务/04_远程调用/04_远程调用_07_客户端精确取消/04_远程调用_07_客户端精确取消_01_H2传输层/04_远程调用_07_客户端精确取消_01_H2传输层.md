## 2. 任务内容 <a id="content"></a>

1. **自持 h2 客户端传输层**：新增 `client/transport/` 子包（`base` / `connection` / `stream` / `pool`），自管连接、并发流、流生命周期、读写与流控；`RpcClient` 不再经 `httpx`。
2. **`RpcTransport` 协议**：`send(request) -> response`、`aclose()`、`stats()`；值对象 `RpcHttpRequest`（含 `trace` 供日志关联）/ `RpcHttpResponse`（含 `stream_id`）/ `TransportStats`；异常梯度四条（超时 / 连接关闭 / 协议错 / 不支持 scheme）。
3. **单连接单读取任务 + 每流队列**：`receive_data` → 事件分派（响应头 / 数据 / 结束 / 对端 reset / 窗口 / SETTINGS / GOAWAY / PING），h2 状态机只在读取任务里被推进。
4. **流中止原语**：`H2Stream.reset()` 发 `RST_STREAM(CANCEL)`，按流状态短路（已结束不发帧）；用例证明「只影响本流、同连接第二条流照常 200」（对应实施前 spike 结论 C）。取消路径接线归 [04-7-2](../04_远程调用_07_客户端精确取消_02_取消发重置帧/04_远程调用_07_客户端精确取消_02_取消发重置帧.md)。
5. **按 origin 分池**：每 origin 一条连接、对端 `SETTINGS_MAX_CONCURRENT_STREAMS` 限流、冷启动建连去重、空闲回收、不可用即摘除重建；`aclose()` 关池并取消读取任务。
6. **TLS 起步就位**：`https` 走 TLS 且 ALPN 必须协商到 `h2`（否则协议错，不静默降级）；用静态自签证书夹具覆盖。
7. **删除 `timeout_ms` 别名**：构造与调用两处一并删（04-5 尚未适配，是唯一零成本窗口）；回写 04-2 详细设计 §8.1 与决策 13。
8. **测试注入面迁移**：`tests_support` 提供 `AsgiRpcTransport`（进程内真 app）与 `ScriptedRpcTransport`（造帧 / 抛错）替代 `ASGITransport` / `MockTransport`；`tests_support/h2_server.py` 提供裸 h2 服务端夹具（正常 / 慢 / 大 / 主动 reset / GOAWAY / 断连 / TLS）。
9. **依赖调整**：`h2>=4.1` 提为 `services/msg` 直接依赖；`httpx[http2]` 降为 dev 依赖（生产代码不再 import）。

## 3. 完成标准 <a id="accept"></a>

- 生产路径真 h2 往返不经 `httpx`；`RpcClient` 对外签名只少 `timeout_ms`，其余与错误码不变（04-5 适配面零改动）。
- 流中止原语在真 h2 服务端上可断言：`RST_STREAM` 只作用于本流，同连接其它流正常返回。
- 异常梯度四条各有用例，映射到 `RpcCallTimeoutError(350004)` 与 `RpcCallError` 不变。
- 存量客户端用例全部迁到新注入面并通过；`services/msg/src` 下不再有 `import httpx`。
- 变更模块行 + 分支覆盖率 100%，静态检查全绿，文档三项（links / docs-scope / eol）通过。
