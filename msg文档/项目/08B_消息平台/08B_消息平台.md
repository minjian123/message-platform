- **8B_00**：需求、总体设计、协议与存储选型、PoC 计划。

## 4. 依赖与风险 <a id="dep"></a>

- **依赖**：bms 07C 产品接入机制（产品声明 / 服务目录 / 表归属 / 域布局）、bms 基座（认证 / 租户 / 审计 / 事件契约）、mdm 作为产品仓参考。
- **风险**：L3 范围大（broker + HA + 管理台）；自研持久化 / 复制 / 顺序的工程风险；与 bms 迁移耦合；单人运维。
- **缓解**：先 8B_00/01 设计与 PoC，用数据决定是否继续；单机 + 本地 WAL 先行，HA 后置；适配层 + 回滚开关。
