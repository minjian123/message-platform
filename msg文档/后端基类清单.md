# msg 后端基类清单

> **产品仓自持**的基类登记表：只登记**本仓可被继承的类**。平台基类体系（体系根、分层、逐类契约）的权威在 bms《后端基类清单》与《后端基类实现契约》，本文件不复制、不改写平台基类。

## 1. 用途与维护 <a id="purpose"></a>

- **定位**：回答「msg 仓里有哪些类可被继承、父类是谁、代码在哪、由谁承接」。平台基类（`BaseValueObject` / `BaseDataContract` / `BaseSchema` / `BaseFrameworkObject` / `BasePluggable` / `BaseRepository` / `BaseService` / `BaseModel` 等）不在此登记。
- **强制口径（平台基类体系，不得违反）**：
  1. 本仓任何类都必须能追到**平台体系根**；
  2. **不得新增体系根**——直接继承 `BaseObject` 一律拒绝，体系根由平台契约定；
  3. 新增可继承类须**先登记本表 + 在实现契约 §7 补链**，再写代码。
- **状态取值**：`已交付` / `占位`（接口就位、真实实现待回补）/ `待交付`（已设计未落地）。
- **代码位置口径**：包根相对路径（本仓包根为 `backend/services/msg/src/`，即 `bms_msg/...`）。

## 2. 基类登记表 <a id="registry"></a>

消息平台的存储 / 队列端口统一为**框架对象**（继承 `BaseFrameworkObject` + `ABC`），按能力细分，具体实现按部署形态注入（文件 / 内存 / 后续外部存储）。

| 类名 | 层 | 父类 | 代码位置 | 职责 | 状态 |
| --- | --- | --- | --- | --- | --- |
| `MessageStore` | 消息存储端口 | `BaseFrameworkObject` | `bms_msg/broker/log.py` | 分区日志读写、位点推进 | 已交付 |
| `DelayStore` | 延迟存储端口 | `BaseFrameworkObject` | `bms_msg/broker/delay.py` | 延迟消息落盘与到期扫描 | 已交付 |
| `GroupStore` | 消费组状态端口 | `BaseFrameworkObject` | `bms_msg/broker/group.py` | 组位点与成员状态 | 已交付 |
| `OffsetStore` | 位点存储端口 | `BaseFrameworkObject` | `bms_msg/broker/offset.py` | 位点持久化与重置 | 已交付 |
| `DeadLetterQueue` | 死信端口 | `BaseFrameworkObject` | `bms_msg/broker/deadletter.py` | 死信投递与保留策略 | 已交付 |

## 3. 不入清单的两类 <a id="excluded"></a>

- **结构契约（`Protocol`）**：`CloseableStore` / `RebuildableDelayStore` / `FlushableOffsetStore` / `DelayDedupeSource` / `OffsetEnumerator` / `OffsetPurger` / `OffsetRealigner` / `OffsetResetter`。它们靠**结构类型**约束实现，不参与继承体系与 MRO；一旦改为需要继承的基类，必须改为继承平台基类并登记本表。
- **数据契约与业务类**：如 `TopicItem`（`BaseSchema` 派生）与各 `BaseModel` / `BaseService` / `BaseRepository` 派生类，直接继承平台基类，不构成新的可继承层。

## 4. 与平台基类的关系 <a id="platform"></a>

- 五个端口均直接继承 `BaseFrameworkObject`（非数据对象的框架对象体系根），与平台内部同形态写法一致（`BaseFrameworkObject` + `ABC`），不新建中间层。
- 端口**只声明抽象方法**，不实现存储细节，也不承载公共字段；公共语义由平台对应层基类维护。

## 5. 维护 <a id="maintain"></a>

新增 / 调整本仓基类须同步：本表 + [实现契约](设计/基类体系/后端基类实现契约.md) §7 链 + 对应任务设计；判定由预检步骤「基座：check_backend_base」承担（继承链对账 / 清单对账 / 直继承合法性 / 数据类形态 / 错误码段位 / 迁移链）。
