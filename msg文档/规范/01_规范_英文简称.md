## 1. 适用范围 <a id="scope"></a>

本规范约束 msg 产品的标识符命名；通用命名规则以 bms《[命名规范](../../bms文档/规范/命名规范.md)》为准，本文件只登记 msg 专属取值。

## 2. 标识符 <a id="ids"></a>

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 产品键 | `msg` | 产品档案、产品路由、前端包来源 |
| 服务键 | `msg` | 服务目录 `service_key` / `module_key` |
| 表前缀 | `msg_` | 产品表统一前缀；基础设施表按基座口径 |
| 业务码 | `msg` | 权限码业务段（如 `msg:query` / `msg:manage`） |
| 事件域 | `msg` | 事件命名 `msg.{对象}.{动作}` |
| 错误码段 | `35`（暂定） | 5 位错误码段位，最终以 07C 登记为准 |
| 内部 API | `/api/v1/msg/...` | 服务内公开契约 |
| 对外 API | `/api/msg/v1/msg/...` | 网关外部命名空间 |
| 库名前缀 | `msg` | `[database].name_prefix`；`prefix == service` 去重 |

## 3. 命名示例 <a id="examples"></a>

| 类型 | 示例 |
| --- | --- |
| 表 | `msg_topic` / `msg_partition` / `msg_consumer_group` / `msg_offset` / `msg_message` / `msg_dead_letter` |
| 事件 | `msg.message.published` / `msg.consumer.rebalanced` / `msg.dead_letter.created` |
| 权限码 | `msg:query` / `msg:manage`（管理模块） |
| RPC 能力 | `msg.rpc.invoke`（能力名，最终以能力目录登记为准） |

> 表名与事件名在 8B_00 详细设计中定稿；本文件只约束前缀与形态，不提前冻结清单。
