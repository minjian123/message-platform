# msg · 消息平台

> BMS 平台之上的独立消息产品：事件总线 + RPC + 管理台（8B 阶段，设计先行）

**msg** 是 BMS 平台之上的独立产品，目标是自研一套**消息平台**：统一承载事件总线（发布 / 订阅 / 消费组 / 顺序 / 重试 / 死信 / 重放）与同步 RPC（请求 / 响应 / 超时 / 流式），逐步替换平台现有的 RocketMQ 事件投递、事务性发件箱与 `HttpServiceClient` 同步调用。

> **当前状态**：**8B_00 立项与总体设计阶段**。仓库骨架、产品声明与设计文档先行；8B_01 PoC 通过后再进入实现。

## 边界

- 本仓只做**消息平台产品**：broker、协议、存储、客户端、管理台、运维。
- 平台运行必需的用户 / 角色 / 菜单 / 权限 / 字典 / 参数等仍属 **bms 基座**，不在本仓。
- 与 mdm 同构：独立仓库、独立服务、独立库、独立部署，经产品声明接入 bms 基座。

## 推送入口

```bash
cd backend
uv run engkit links --root ..          # 文档相对链接与锚点
uv run engkit docs-scope --root ..     # 进度类字段只允许落在阶段计划
uv run engkit push --root ..           # 先预检、通过才推送（须先提交）
```

> 预检是推送的内部步骤，本地手动 `engkit preflight` 会被拒绝；口径见 bms 仓《工程化工具包说明》。
